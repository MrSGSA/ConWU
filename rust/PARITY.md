# Rust 整体替换验收

对照基线：正式版 `1.4.5`（`8eaffab`）。此表是发布门槛，不能用“可编译”或六协议连通代替全部验收。当前生产程序未替换，GitHub/Gitee 未发布。

| 原有功能 | Rust 实现 / 验收状态 | 正式切换门槛 |
| --- | --- | --- |
| 六固定协议、手动选协议 | Linux 真实外层配对及双向加密包通过 | Windows 真实网卡、Windows/Linux 互通 |
| 自主打洞、第三方已有入口 | 两种模式均有独立实验；六协议协同 + TUN 双向 ping | WAN 抓包和恢复验证 |
| Windows Mimic 纯 XDP | helper 已接入 Generic AF_XDP，无 WinDivert 回退 | 实机收发、持续业务和资源释放 |
| FakeTCP 同源观察、prepared-start、捕获所有者 | Rust 管理 ABI、PID 绑定、捕获排他、确认退出；Linux 强制协同成功 | Windows 原生 broker、取消/重启同端口 |
| v3 签名 traversal 与历史受管路径 | 消息签名、校验及协调邮箱已迁移，.NET 双向互通通过 | runtime 状态机、SLF1、路径提名、现行研究选项逐项核对 |
| 16 符号直连码、SAS、主机审批 | 原有协议主路径通过；IPv6 扩展码保留 | 跨版本配对与交付重试 |
| 旧成员重新加入 | 凭据、历史、重发身份及防撤销复活已实现；.NET 对照通过 | 主机重启、交付丢失、重新申请实测 |
| 直接入口申请 EntryAdmission | 兼容处理、SAS 审批已接入 | 多网络选择、被占用网络拒绝测试 |
| 多网络、各网络独立设置与直连码 | 本地回归及 UI smoke 通过 | 生产配置导入、三机多网并存 |
| 自定义虚拟 IP、虚拟网段冲突检查 | 核心及后台实现 | Wintun / TUN 实机验证 |
| 断开 / 重新连接、最小发现保活 | 原有主路径回归通过 | 断开期间地址变化、恢复 |
| 退出、通知主机、移除从机、解散网络 | 签名通知、持久化重试、撤销检查通过 | 双方重启和离线退出 |
| DNS TXT / HTTP 订阅更新、TTL 修复 | 多解析器、不使用过期首次入口 | 真实订阅变更和开机复连 |
| PKARR 地址与启动状态交换 | 签名、过期、序号持久化、加密状态对照通过 | 公共网关失败及重启恢复 |
| 自有 UPnP / PCP / NAT-PMP 映射 | 默认 UPnP，其他两者尊重高级开关；模拟续租归属验证通过 | 实际路由器及出口切换 |
| IPv6 | TCP / HTTPS 外层及直连码已实现 | 真实双栈；不把其余四模式冒称为 IPv6 |
| TCP / HTTPS 三连接分流 | 现有核心握手、独立连接及故障收敛回归通过 | WAN 持续业务 |
| UU 远程自动多网络接管、双端开关 | Rust 路径、进程持有及计量已实现 | 真实 UU 串流必须确认流量经 ConWU |
| 原 WebUI、日志、流量图、网络选择 | 嵌入现有资源，smoke 通过 | 迁移后的全页面与设置错误呈现 |
| Windows 托盘、开机启动、服务 | 原生 Rust 实现 | MSI 安装 / 维护 / 重启 / 会话切换 |
| Linux CLI | 管理命令已补实现 | 命令集回归、SIGTERM 和 systemd |
| 对外协调、证书、客户端列表 | 独立角色已实现 | 旧协调记录与高水位迁移 |
| 协调备份 / 检查 / 显式恢复 | 兼容 `.slcoord`，恢复标记阻止混合代次启动 | 损坏包拒绝、完整旧备份兼容 |

| GitHub / Gitee 更新检测、下载、校验 | 现有下载恢复回归通过 | Rust MSI / Linux 包更新回滚与恢复组网 |

| 安装包、依赖、许可证、Linux libc 兼容 | 尚未形成最终包 | 兼容实际 Linux；保留驱动/helper 许可证 |
| 一份完整上一版回退 | 生产文件尚未修改 | 程序、完整设置、MSI 源；失败恢复演练 |

已退役的直接 UDP、自动协议回退和多成员治理不重新加入产品。保留在旧源码中的比较夹具不能默认为当前公开功能；现行高级选项需单独核对，不能静默忽略。

发布前全部必要项通过后，使用同一份已验收的构建产物整体替换并发布到 GitHub 与 Gitee。任一必要项失败，继续修复并保留当前版本。
