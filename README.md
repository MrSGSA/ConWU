# ConWU

原名 StreamLink。当前开发候选为 `1.1.0-preview.1`：每个网络连接两台设备，一台设备可以同时创建、加入多个网络，概览统一显示。现有 GitHub Release 尚未替换；本次架构更新需备份后全新设置，见[实施记录](docs/aq1/双机多网络实施记录-20261108.md)。

想在外面用 Moonlight 连家里的电脑，却碰上 UDP 限速？ConWU 就是为这件事做的直连组网工具，支持 Windows 和 Linux。

两台电脑装好后，通过虚拟 IP 连接。平时放在托盘里，需要操作时打开 WebUI。

[下载最新版](https://github.com/MrSGSA/StreamLink/releases/latest) · [使用说明](docs/使用指南.md) · [1.0.5 更新说明](docs/releases/v1.0.5.md)

Windows 与 Linux 都能创建、加入网络，也能兼任 HTTPS 协调服务。协调设备不自动成为成员，不转发串流。Linux 候选的安装与验证范围见 [Linux 说明](packaging/linux/README.md)。

## 能做什么

- 默认使用 **FakeTCP＋HTTP**，也可手动选择 UDP。连接失败时不会擅自切换协议。
- 可以选择自主打洞，或使用已有的公网地址、端口映射及其他工具打通的入口；已有入口模式只连接这些入口，不会同时尝试自主打洞。
- 已有入口可由 Lucky 等工具直接更新到共用域名下的设备专属 TXT；ConWU 自动读取，手动地址和订阅作为备用，第三方无需覆盖软件的签名记录。
- 支持 HTTPS 地址订阅，入口变化后自动更新；已有健康连接继续保持。
- 在 WebUI 中创建或加入网络，查看设备、延迟、流量和连接进度。
- 提供 MSI 安装、更新和卸载，支持后台服务与开机托盘。

## 开始使用

1. 在两台 Windows x64 电脑上安装 Release 中的 `.msi`。
2. 一端创建网络；另一端在“加入网络 → 可达入口”填写它的可达地址或订阅链接。地址需要通向 ConWU 接收端口，新安装默认 `44680`，升级保留原值。
3. 也可以在两端填写相同的 HTTPS 协调入口，使用六位配对码申请加入。两种方式都由获准设备核对校验码后批准。
4. 把对方的虚拟 IP 填进 Moonlight，开始串流。

目前需要自建协调服务或准备可达入口，还没有公共协调服务器。安装包带齐运行组件，使用者不需要另装 .NET、Python 或开发工具。

1.1 的双机授权和共享接收格式需要两端一并更新。一个网络包含一台审批主机和一台从机，通道双向；不同网络互不转发。共用裸入口有多条待配对网络时，使用明确绑定网络的邀请。默认接收不代表公网已经可达。

## 使用前了解一下

不同网络的打洞和限速情况差别很大，ConWU 不能保证所有环境都能直连。建议先用较低码率试一下，再调到自己常用的设置。

业务流量在设备之间直传，协调服务不转发串流。FakeTCP＋HTTP 的外层没有 TLS，内层数据由 ConWU 认证加密；HTTPS 用于协调和地址订阅。

此前版本已在作者的两台 Windows 设备上使用。1.0.5 重点修复设置被网络操作改写、后台反馈和输入刷新问题，补齐实际入口与直连计时；安装升级和两端日志已核对，验证范围随 Release 提供。八台 Windows 同时运行、跨账户及长时间大码率公网串流仍需要继续验证。新的抗 QoS 方法先做独立实机实验，尚未加入软件。
