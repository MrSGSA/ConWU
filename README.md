# StreamLink

想在外面用 Moonlight 连家里的电脑，却碰上 UDP 限速？StreamLink 就是为这件事做的 Windows 直连组网工具。

两台电脑装好后，通过虚拟 IP 连接。平时放在托盘里，需要操作时打开 WebUI。

[下载最新版](https://github.com/MrSGSA/StreamLink/releases/latest) · [使用说明](docs/使用指南.md) · [1.0.2 更新说明](docs/releases/v1.0.2.md)

## 能做什么

- 默认使用 **FakeTCP＋HTTP**，也可手动选择 UDP。连接失败时不会擅自切换协议。
- 自己尝试建立直连，也能使用已有的公网地址、端口映射或 Lucky 打洞入口。
- 支持 HTTPS 地址订阅，入口变化后自动更新；已有健康连接继续保持。
- 在 WebUI 中创建或加入网络，查看设备、延迟、流量和连接进度。
- 提供 MSI 安装、更新和卸载，支持后台服务与开机托盘。

## 开始使用

1. 在两台 Windows x64 电脑上安装 Release 中的 `.msi`。
2. 打开 WebUI，选择自选协调服务器，或填写已有入口。使用已有入口时，地址需要通向主机的 StreamLink 接收端口，默认是 `44680`。
3. 一端创建网络，另一端申请加入，由主机确认。服务器组网用六位配对码，无服务器组网用直连邀请。
4. 把对方的虚拟 IP 填进 Moonlight，开始串流。

目前需要自建协调服务或准备可达入口，还没有公共协调服务器。安装包带齐运行组件，使用者不需要另装 .NET、Python 或开发工具。

## 使用前了解一下

不同网络的打洞和限速情况差别很大，StreamLink 不能保证所有环境都能直连。建议先用较低码率试一下，再调到自己常用的设置。

业务流量在设备之间直传，协调服务不转发串流。FakeTCP＋HTTP 的外层没有 TLS，内层数据由 StreamLink 认证加密；HTTPS 用于协调和地址订阅。

此前版本已在作者的两台 Windows 设备上使用。这次主要更新 WebUI、全局设置与邀请审批，已完成隔离实例和本地链路验证，公网串流效果仍需实际确认。多设备功能保留，八台 Windows 同时运行、跨账户及更长时间的稳定性仍需要继续验证。完整记录随 Release 提供。
