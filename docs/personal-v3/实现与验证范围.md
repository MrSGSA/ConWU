# 个人功能 v3 实现范围

基线为 8ed0617015c02b9a11f6d7b5380a43bc2f8e07af，独立分支 feature/personal-v3。唯一执行规格为 releases/Personal-Preview/StreamLink-Personal-Feature-Handoff-v3-8ed0617；旧 v1/v2/公众 M0—M9 不叠加。此文记录实现，逐项实测和最终双轴状态由候选目录中的交付报告及 delivery-status.json 固定。

新增：编译期个人 edition；独立服务/管道/配置/安装/桌面目录与端口；类型化 PacketAdapterBackend（拒绝数字及任意路径）；实际 provider 工厂与切换前准入；个人增强预设、准备检查、后端选择；非秘密三层状态（网卡/建链/承载）；完整 self-contained 个人打包管线、匹配协调与真实 SYS/INF/CAT/DLL。

复用而非重做：原 TCP lease/唯一捕获 broker、原生 SO、来源学习、共同提名、UDP 同 socket、条件预测与观察、预算、pacing、MeshLink/Wintun、自研 NDIS miniport与用户 DLL。原 HTTP/SEQ、无外层业务重传、无中继、健康 Active 保护与标准 RequireProduction 保持。普通标准构建默认依然 Wintun/legacy。

自研准入：仅固定受保护安装目录；文件集和包指纹；SID/ACL/无重解析点；本机有效批准；独立内核证据；适用签名、唯一实际设备、实际加载映像哈希。没有这些时在停止健康网卡之前拒绝切换。产品不会使用研究构造函数中的任意 DLL/index/bool 入口。

生命周期夹具 v2：同一长寿子进程可配置轮数，外部 watchdog，仅终止自有测试进程。3 秒 I/O/close 门槛不变；原历史即时 PnP 不可见 Fail 不改写。增加实际 LUID 的只读诊断导出（bridge descriptor ABI 仍为 2），采用 GetIfEntry2Ex 无统计定向查询，避免全量枚举与恒定 LUID/index 映射误判；日志排队写出避免在关闭回调中阻塞磁盘。实际超时仍标 Fail，不把这些夹具调整称作已修复官方驱动的所有关闭延迟。

来源学习夹具：固定每端收到的公告偏移及实际 tuple；正确公告端无需 Learned，偏移端须实际认证后学习并冻结。错身份和旧轮次保持负例；transportOutcome 与 scenarioVerdict 独立。正确服务端收到 SYN+ACK 替代错公告导致未到达的 bare SYN，是来源学习场景的不同包序；普通 SO 仍要求交叉 SYN。

测试通过的含义：Model、真实用户态 I/O、实际 WinDivert、Wintun、物理 WAN、内核 self-TUN 分列。旧 overlay 上真实 SO 不等于校园网 NAT 新收益；同 socket 的认证小包不等于 1344B payload 的 DF 业务能力。缺外部资源单列 BlockedExternal；测试失败保留原输出。不启用全局 Verifier、测试签名或改变安全策略。

构建：`dotnet publish ... -p:StreamLinkPersonalFeature=true -p:StreamLinkReleaseVersion=1.0.0-personal-feature.2`。完整个人包由 scripts/Package-PersonalFeature.ps1 在干净的固定 HEAD 生成；标准 Package-RC.ps1 的 RC-only 契约没有改变。PF2 的代码/证据范围见《PF2-有限交付范围》，不能用版本号晋升未验证能力。

目前未提供自研完整内核自动测试/批准发行器：有受限安装/只读盘点与门槛模板，但 IRP 分支、Verifier、跨环境批准证据需要实验机与签名，不能以模板作为 Pass。这部分明确 PartialCode，不宣称驱动可在日用双端使用。

官方依据：[Inf2Cat](https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/inf2cat)、[PnP catalog](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/creating-a-catalog-file-for-a-pnp-driver-package)、[GetIfEntry2Ex](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/nf-netioapi-getifentry2ex)、[驱动签名路线](https://learn.microsoft.com/en-us/windows-hardware/drivers/dashboard/driver-signing-offerings)。生成 CAT、签名接受、实际业务和内核安全是独立证据。
