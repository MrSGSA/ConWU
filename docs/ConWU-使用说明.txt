ConWU（原 StreamLink）

这是统一设备候选版本的使用说明。当前正在构建与部署验证；以随包发布说明和实际验证记录为准，不能把旧版本的通过记录视为本版验收。DDNS 为默认关闭的可选功能，真实 Cloudflare 发布还需要配置本机令牌。

安装与更新
Windows 使用 ConWU-版本-x64.msi，日常从 ConWU 快捷方式或托盘打开 WebUI。更新前停止串流。MSI 沿用原升级标识、服务和配置目录，保留原设备设置及开机启动选择。卸载仍保留受保护配置。
程序安装在 %ProgramFiles%\StreamLink；ConWU.exe 为新入口，StreamLink.exe 为旧启动项兼容入口，两者进入同一实例。app 目录中的组件名和 %ProgramData%\StreamLink-PersonalFeature 数据目录保留，勿手动改名。
WebUI 固定为 http://127.0.0.1:47821/；会话过期时从托盘重新打开。退出托盘不停止后台组网。
Linux 参见包内 README.md；主命令为 conwu，旧 streamlink 命令、streamlink.service、/var/lib/streamlink 数据目录继续保留。

连接设备
使用协调服务器时，各台设备填写同一个 HTTPS 协调地址。一端创建网络生成六位配对码，另一端申请加入，核对设备与校验码后批准。成员平等管理网络允许已批准成员处理加入和管理请求，不要求最初创建者一直在线。
协调服务可由某台设备的“本机协调服务”提供，独立于该设备是否参与网络。默认不对公网开放，公网使用 HTTPS。仍须有一个可达的协调入口；本版没有协调数据库多副本接管。
“连接设置”中的网络入口可指向网络内任一获准设备；“提供网络入口”填写通向本机接收端口的公网地址、映射或 HTTPS/TXT 订阅。入口不再代表谁拥有网络。
已有入口模式只使用已有入口，不回退自主打洞。订阅内容继续兼容 streamlink=IP:端口 与 #streamlink，不必因改名修改原上报。
原无服务器邀请网络保留原审批方式。由提供可达入口的设备生成直连邀请，另一端在“加入网络”粘贴并申请；邀请仍需批准。新增 DDNS 并未取消此步骤或代替协调。

域名自动发现
可选功能，默认关闭。在“设置 → 域名自动发现”填写共用域名。每台设备自动管理独立的带签名 TXT 记录，用户只需记住同一个共用域名。
提供公网接收入口的设备可开启发布，填写 Cloudflare Zone ID 和限定区域的 API Token。只读设备不需要令牌。首次仍需配对和批准；令牌不随邀请同步。
只发布实际监听对应的可用映射或已配置入口；临时 STUN 地址不等于可达入口。DNS 记录公开，签名保护身份和内容，不隐藏公网 IP。DNS 更新不会断开健康直连。
完整 Cloudflare 操作、权限范围和验证限制见随包 ConWU与Cloudflare-DDNS.md。

串流与设置
把概况显示的对端虚拟 IP 填入 Moonlight。先检查画面、声音与输入，再提高码率。默认 FakeTCP＋HTTP；直接 UDP 是手动选项，失败不切换协议。HTTPS 用于协调和订阅，不等同于业务 TLS。
设置通过“保存全部设置”统一应用；网络创建、退出、删除不改写已保存设置。API Token 留空保留旧值，清除需显式勾选。恢复默认设置不会恢复旧令牌。
保留上一版安装包与本机受保护配置备份。启用新治理规则后不能直接用旧客户端管理同一网络；回退前核对版本能力，不将旧成员表覆盖到仍在使用的协调数据上。
