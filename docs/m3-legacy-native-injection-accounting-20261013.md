# 兼容原生注入与源端点记录

2026-10-13，独立工作树后续实现；不属于正在打包的 `bea3074`。现用服务、网络配置及发布包未替换。

`MeshTransport` 为本次受管子进程设置本地 ResourceId，native 在真正发送 API 成功后统计外层 IP 字节和包数。沿用原生既有报文类别元数据，记录握手、维护、业务、完成和诊断；未知普通应用帧不凭长度获得业务类别。另记发送失败、实际捕获接收、队列丢弃、已抑制出站，以及成功 raw 帧里的首个实际源端点。来自其他源的包单独计数，不把首个源误称唯一出口。

`SLW1` 是本地输出协议，不进入 TCP/UDP 线路。只包含实例标识、头部信息与累计数字，无业务载荷/密钥。每秒最多一份普通快照；一个独立写线程合并最多一份待写快照，主协议循环不写 stdout。观察线程及其有界状态与进程共生，由现有 JobObject 的进程退出完成回收；停止捕获的结束快照不是进程已退出证明。强制退出或输出中断可能缺失最后计数，必须保持 Unknown/不完整。broker 已在父进程计账，禁止在这里重复计算。

C# `ChildJob` 在日志关闭时仍分流本地记录。ResourceId 精确匹配、格式/范围/包长一致性、递增序号与累计单调性经过校验，旧/错误记录不能覆盖状态。兼容资源表持有最近报告，精简 IPC 保留当前已报告/未报告进程数及已知注入总量。所有聚合仅针对当前仍登记的资源，不是终身设备总数；缺失报告不解释为零。字段范围额外限制以防多资源求和溢出。
