# rc.12：本机操作进度 403 与标签页图标

接续 `8d096f190a6e52ba794491c2f47d8db7931cde47`，MSI 版本递增为 `1.0.18`。

## 原因与行为

rc.11 的服务会在操作超过 700 ms 后返回已受理状态，由浏览器读取
`GET /api/status?operation=<UUID>`。WebPanel 顶层却仍拒绝所有查询参数，
使正常进度查询返回 403。后台操作不随浏览器报错取消，因此出现创建、删除或
解析已经执行，界面仍报错的现象。两端共享这段本机代码，与两机虚拟网段无关。
该证据不意味着任意远程订阅源的 403 也由本机引起。

现在只允许上述路由的一个 `operation` 参数，要求非空、36 字符 D 格式 UUID。
其他路由、额外或重复参数仍拒绝；会话、Host、Origin、Fetch Metadata、CSRF、
限流、SID 管道授权与请求去重保持原约束。UUID 只用于选择操作，不是访问凭据。

已受理操作的进度查询遇到临时连接故障或 429/502/503/504 时，在原有等待期限内
重试读取，不重新提交变更。授权失败不自动重试。确认成功后清除旧提示；
实际操作失败继续显示；超过期限明确表示结果未确认。

标签页改用 `/streamlink-tokyo-45.svg`，映射到与应用标志一致的现有 SVG。
新路径避开旧图标地址的缓存，仍发送 `no-store`，不增加外部资源和前端依赖。

## 回归安排与边界

先保留旧实现真实 HTTP 路径失败的日志，再测试合法与非法进度查询。
浏览器夹具改为真实 WebPanel → 受限 Windows 命名管道 → 隔离 ControlWorker，
故意占用变更队列超过 700 ms；验证解析、删除、创建拒绝、设置修改的受理与完成，
以及一次受控 503 后恢复、成功清理提示、真实错误保留和图标一致性。
删除使用仅一成员且未启动网卡的夹具，不是公网组网效果测试。

两轮分离自审后冻结候选。最终核心使用 `InstallerRefresh`：覆盖相同核心项目各一次，
不冒充新的 30 轮可靠性结果。交付前验证实际发布文件、隔离 MSI 安装/修复/卸载、
普通用户首次面板及已安装主机的操作查询与图标。具体结果以候选目录
`delivery-status.json` 和 `verification/` 为准。

保留 rc.11 回退包；本轮不替换日用安装，不远程更新 Akane，不改变传输和 DNS 实现。
两端安装 rc.12 后关闭旧 WebUI 标签页，从托盘重新打开即可使用新资源。
公网长串流、正式八机及其他 E3 门槛仍未全部验收。
