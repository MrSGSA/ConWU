StreamLink 1.0.1-rc.7 修复候选：安装、更新和卸载

推荐安装
1. 双击 StreamLink-…-x64.msi，按提示安装并完成 UAC。安装完成后可直接启动 StreamLink。
2. 桌面和开始菜单都有带 S 图标的 StreamLink，唯一主界面为浏览器 WebUI。日常使用普通账号打开；首次安装为运行安装程序的日常账号授权，后续更新保留既有授权。
   后台随系统启动；授权日常账号登录后自动显示托盘并准备 WebUI，不自动弹浏览器。右键“打开 WebUI”即可进入。
   本机面板固定为 http://127.0.0.1:47821/。会话过期后从托盘重新打开；端口占用时会说明原因，不随机更换端口。
3. 两端保留已有配对与配置；首次配对时填同一个 HTTPS 协调地址，创建/六位码加入并核对双方校验码。本次入口 https://streamlink-personal.space4sgsa.com/ 已于 2026-10-31 恢复。stun.space4sgsa.com:3478 是独立 STUN 地址，不能填入 HTTPS 协调栏。
4. 在“连接”首页复制对端虚拟 IP 启动串流；先低码率，再测试目标码率和实际声音、输入、画面。真实双机效果仍需本人试用。

更新
运行较新版本 MSI 即可。安装程序关闭先前的 StreamLink 界面/托盘/本机面板，安全停止个人服务，再更新并重新启动。
更新和修复会等待旧网络进程完全退出，自动卸载本实例遗留的 Wintun 网卡，并等待 Windows 完成移除后再启动新版。没有其他 Wintun 网卡时，使用官方接口清理闲置驱动；其他程序的网卡与共享驱动保留。ZIP 手动安装也执行同样清理。
本版修复笔记本更新时的 1722 错误：设备节点已经移除，但 Windows 仍保留旧接口记录时，会通过官方 Wintun 创建并立即关闭同一身份来恢复接口状态，再等待清理完成。只处理已停止的本实例；不启动临时网络会话、不更改 IP、不停止其他网络软件。此恢复操作已在发生问题的 Thinkbook 上验证无需重启；实际新版安装结果见交付报告。
默认安装采用 Windows Installer 的版本规则，复用版本未变的官方驱动和运行库，不再强制覆盖正在加载的同版 WinDivert64.sys。程序文件随 MSI 版本递增；最终安装后仍校验完整包。显式使用 /famus 强制覆盖所有文件、实际更换驱动版本或 Windows 已有待重启操作时，仍可能提示重启。
网卡仍被活动实例持有时不会强删。Windows 明确要求重启或迟迟无法完成移除时会中止并恢复安装，不会假装更新成功；这不能保证所有 Windows 驱动故障都免重启。维护记录在 %ProgramData%\StreamLink-PersonalFeature\wintun-upgrade.jsonl，失败详情在 installer-error.log。
受保护的配对、设备配置和日志位于 %ProgramData%\StreamLink-PersonalFeature，更新保留这些内容。
旧自动选路配置在首次加载时备份为 profile-before-fixed-transport-*.dpapi，再迁移为固定协议；默认 FakeTCP＋HTTP，原来明确创建的 UDP 网络保留 UDP。设置内可自行切换，两端需选择相同模式。连接失败只重试所选协议，不自动回退或升级为另一协议。
本机已卸载的 0.3.2 不会恢复。如果其他机器仍装有旧版，安装会关闭旧界面并保留旧服务与配置；旧版以前台方式维持网络时会提示先停止，避免强制切断唯一通道。
失败时 Windows 安装事务恢复文件与原服务配置；原授权也单独恢复。安装期间不要强行启动第二个后台进程。

卸载与修复
Windows“设置 → 应用 → 已安装的应用 → StreamLink”可修复或卸载，开始菜单也提供卸载入口。
卸载先关闭界面并停止个人服务，删除本次安装的程序、快捷方式和托盘登录自启项。配对配置和日志继续保留；不删除共享 Wintun/WinDivert 驱动，不卸载旧 0.3.2。
托盘只保留“打开 WebUI”和“退出”；悬停可查看版本、后台状态、设备名与虚拟 IP。退出托盘仅关闭本机面板，网络继续运行。
修复请重新运行 MSI，或使用 Windows 的已安装应用；后台已停止时可在 services.msc 启动 StreamLink 个人后台。

文件布局
%ProgramFiles%\StreamLink\StreamLink.exe：日常启动入口。
%ProgramFiles%\StreamLink\app\：程序、运行库、WebUI 和官方驱动组件。无需手工整理或删除其中 DLL。
顶层的使用说明与布局清单用于诊断。无需预装 .NET、Node、Python 或 WSL。

ZIP 备用方式
解压 windows.zip，普通双击顶层 StreamLink.exe 打开 WebUI。内部程序在 app 目录。首次使用推荐先安装 MSI；需要手工安装 ZIP 后台时，在解压目录用提升的 PowerShell 执行：
.\app\StreamLink.exe --install --ui-user-account "计算机名\日常用户名"
已有 MSI 安装时，更新和卸载统一交给 Windows 安装程序。

边界
此版修复更新时旧 Wintun 接口记录残留导致的安装失败，以及强制覆盖相同 WinDivert 驱动造成的重启提示，保留固定协议、托盘自启和固定 WebUI 地址。产品版本 1.0.1-rc.7 对应 MSI 1.0.13；旧包保留。用户已确认 rc.3 恢复到 FakeTCP 后画面正常，这不是本包长时间串流验收。请在停止串流后更新；真实双机长时间串流、物理穿透覆盖和正式八实例验证仍按交付报告记录。
默认业务仍为 FakeTCP＋HTTP 前导＋MeshLink，HTTPS 为协调控制。关闭耗时偶有超过 3 秒目标，请等待停止完成。

当前已知限制：历史连续停启曾出现 Wintun 创建失败 4319（Windows 设备查询超时、网络类配置未完成）。本次解决的是已确认的旧接口残留安装失败，不能据此宣称所有 4319 或 Windows 重启状态均已根治。若仍失败请保留 installer-error.log 和 wintun-upgrade.jsonl。界面/安装可用不等于网络日用与双机串流已验证，请以交付报告为准。
