# 1.0.5：设置、界面状态与本机控制接口

基线：1.0.4 / `8b69ec3b`。保持已有入口独立连接、固定协议和 FakeTCP＋HTTP 数据语义。本轮不加入新的抗 QoS 传输。

## 现场与根因

Thinkbook 与 Akane 的日用日志显示，退出和重建期间服务进程没有重启；笔记本曾等待 `owned-rule-and-record` 清理，随后在原 `:8463` 入口重新通过认证。界面提示不能据此写成公网断线或后台进程消失。

本机受限管道原先直接调用异步操作，调用方可能在首次让出线程前执行同步取消回调、配置写入或 Windows 操作，堵住接收循环和 700ms 受理回执。定向回归保留其它代码、仅恢复原内联调用后重现超时；移出接收循环后通过。真实 Runner 的规则回收阶段注入阻塞时，状态、操作编号、排队操作和设置仍可读取，停止完成后仅执行一次。

前端还有独立问题：任意一次请求失败都会覆盖刚收到的成功状态；后台标签页的计时节流也会触发 10 秒提示。现以新鲜成功状态为准，恢复可见时立即读取并给予有界等待；确认停止、访问拒绝、授权过期仍明确报告。授权过期不会被迟到的成功回复抹掉。停止网络时发布“正在停止网络”，旧运行器不能把它覆盖为已直连。

## 设置的写入边界

保存的网络设置独立存储为 `SavedNetworkSettings`。已有版本首次升级从其原界面语义迁移，不改入口文本、端口、协议、STUN、请求 IP、协调地址等内容；原网卡迁移仍先备份原文件。邀请、成员编号和运行时发现只修改运行态。创建、加入、退出、删除、重新加入、启动/停止、批准和目录更新不写用户设置副本。

设置页保存、受限字段补丁和原管理接口的显式保存才更新设置。设置版本标识取自用户副本，网络生命周期不会使其无故变化。主机入口使用稳定目标引用；旧成员入口保留为未启用内容，不按新网络碰巧相同的编号启用。同一网络经过批准的成员替换可重绑运行态，不改用户填写内容。

同机升级保留设置和既有网络身份。测试用 1.0.4 真实 MSI 装入非默认参数，再升级候选，比较完整设置指纹、身份、UI 账号和开机启动选择。DPAPI 文件仍留在受保护的 ProgramData 中；本轮没有新增换机导入/导出。不能继承的内容不得静默改为默认值；已有格式无法读取时保留原文件并使更新失败回滚，需说明受影响项目后由用户决定是否重设。

升级检查按设置的功能等价判断，不要求配置文件字节、默认字段表示或内部成员引用完全一致。首份升级验证将旧格式省略的默认 `Direct=false` 读为 `null`，造成工具误判；逐项核对原值后，验证工具按布尔默认值归一化，并用新的隔离配置重新完成实际升级。首轮失败和复跑记录均保留。此修正只涉及验证脚本与本记录，不改变已冻结的应用源代码或安装包。

## 页面与输入

- 设置草稿跨页面、分区、后台状态及进度刷新保留；只有显式保存期间锁住提交中的设置草稿。配对轮询和地址测试不再锁住输入区。
- 创建/删除网络不清除“恢复刚才设置”的历史。恢复默认值只是填入草稿，仍需保存。
- 切换本机/目标入口保留各自内容；切换连接模式保留已有入口的配对选择。刷新周期保存秒数，界面同时记住用户选择的时间单位。
- 不变的下拉选项不在每次状态刷新时重建；设备变化只更新必要选项。没有草稿时，其它窗口的已保存值会更新到输入框；存在草稿时保留并在冲突保存时明确拒绝。
- 成功加入后只清理本次提交的配对凭据；退出时保留用户新输入的下一份配对草稿。六位码规范化并限制可见数字，不再因追加到旧六位值而整行变空。直连邀请文本不被截断。
- 同一浏览器重新打开面板会轮换会话。只有后端明确返回 `SessionChanged`、且尚未登记/执行请求时，前端重新取得当前会话并用原操作编号重试一次；其它 403、丢失回执或已受理操作不重新提交。

## 连接详情

出站已有入口取自当前认证承载客户端，既不使用未验证订阅值，也不显示本地桥接端口。入站多路监听无法可靠映射到某个远端公网端点时，显示“入站直连”和本机接收端口。断开时标注上次确认入口。

已直连时长采用后台双向健康状态的连续计时，显示天、时、分、秒；普通刷新和设备改名不重置，实际断线后重新建立连接会重新计时。秒数原位更新，不重建输入区。

## 正确性与安全检查

核对 Windows 客户端 SID、服务 PID 身份验证、CSRF、会话过期、操作编号重放保护、受理后的服务生命周期、取消归属、必要撤销失败保留网络、状态快照与用户设置分离、跨网络入口不误绑。原始生产日志和配置只保存在受保护的忽略目录，不随源码或候选上传。

## 产品与质量检查

以实际 HTTP、受限管道、MemoryAdapter Runner、真实 TLS 故障服务和浏览器检查整个状态矩阵。覆盖成功、拒绝、超时、取消、丢失回执、并发窗口、后台标签页恢复、慢退出、草稿编辑及恢复。浏览器控制进程有独立生命周期，清理超时保留失败结果并只结束本测试创建的 Edge。

冻结后的完整核心、打包、隔离安装生命周期、旧版本升级和两台实际设备结果另存候选证据。回环、控制接口和短时直连不代替正式长时大码率串流与多机完整矩阵。
