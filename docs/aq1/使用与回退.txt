StreamLink：使用与回退

安装与更新
1. 在各台 Windows 设备上运行本版 StreamLink-…-x64.msi。安装前结束串流；安装器保留现有网络、设置和自启选择。不要在没有独立管理通道的远程设备上强行停止唯一连接。
2. 从桌面、开始菜单或托盘打开 WebUI。关闭浏览器或退出托盘不停止后台网络；暂停连接请在概况中点击“断开”。修复、卸载使用 Windows“已安装的应用”。
3. 程序放在安装目录的 app 子目录，设置和日志放在个人后台的数据目录。ZIP 备用包可解压后打开顶层 StreamLink.exe；手动安装后台需管理员权限。不要跨电脑复制 DPAPI 配置。
4. 协调网络的新功能需要先更新服务器，再更新所有设备。保留原服务器环境变量、HTTPS 入口和数据目录，确认 /health 返回 meshGovernance=1。附带部署脚本仅用于全新隔离部署，不会覆盖已有服务。

建立连接
1. 在“设置 → 协调服务器”中填入可用的 HTTPS 协调地址；网络成员使用同一个服务。公开证书通常不填指纹。STUN 设置单独填写，stun.space4sgsa.com:3478 不是 HTTPS 协调地址。
2. 新建协调网络默认成员平等。由任一获准成员生成六位配对码，另一端在“加入网络”输入；双方核对校验码，再由邀请设备同意。获准设备也会取得邀请、审批、移除成员和解散网络的权限。
3. 旧网络权限不会因安装更新而自动改变。先升级所有设备，再由原创建者在“创建网络”选择“启用成员平等管理”。网络身份、虚拟 IP 和已保存的设置保留。
4. 平等网络的“退出网络”只撤销本机身份；其余成员继续使用。最后一个成员退出会关闭网络。“解散当前网络”影响全体成员。概况中的断开只暂停本机，不退出成员身份。
5. 主动退出的设备保留受保护的重新加入证明，经再次批准，可以用新身份保留原虚拟 IP。被明确移除的设备不能利用旧证明恢复原授权。所有设备只是关机时，不会自动删除网络。
6. 出现“网络变更正在等待确认”时点击“继续确认”，不要重复添加同一设备。若配对房间已消失，可检查设备列表，移除未使用的授权后重新申请。协调暂不可达时，已有健康直连继续；成员变更等待恢复。

已有入口与无服务器邀请
公网 IP:端口、域名:端口、HTTPS/TXT 订阅均可作为入口线索。入口应通向对应设备的 StreamLink 接收端口，默认 44680；Lucky 的探测端口不能与本机 StreamLink 监听端口争用。普通 TCP 代理及其他软件自己的隧道端口不能直接作为该入口。
订阅支持 streamlink=IP:端口；共享订阅在来源末尾使用 #streamlink 选择标记。建议使用带鉴权的 HTTPS 只读订阅，完整链接应保密。订阅周期可调整，地址变更需要重新验证设备身份和双向通信后才切换健康路径。
原无服务器直连邀请网络保持原管理方式：主机填写已有入口、关闭“使用 HTTPS 协调服务器”，生成 SL6. 邀请；加入端粘贴邀请后，由主机核对并批准。本次未扩展无服务器的成员平等管理。
已有入口模式只使用已有入口，不回退自主打洞；如需自主打洞，由用户切换连接设置。

串流与设置
在概况页找到对端虚拟 IP，将它填入 Moonlight。先确认画面、声音和输入，再提高到实际目标码率。两端业务协议必须一致，默认 FakeTCP＋HTTP，直接 UDP 是手动选项，没有自动协议回退。HTTPS 仅用于控制，不能把 FakeTCP＋HTTP 称为真实 TLS 业务。
修改设置后使用“保存全部设置”。切换页面保留草稿；组网、退出和迁移不改写已保存设置。改变端口等连接参数需要确认后重建连接，接收端口不会因冲突而静默改变。
托盘保留“打开 WebUI”“退出”。日常 WebUI 地址为 http://127.0.0.1:47821/；授权过期时从托盘重新打开。面板状态暂未更新不等于串流已断线，日志和连接状态需结合判断。
正式使用 Wintun 与 WinDivert。运行包不要求安装 Lucky、EasyTier、WSL、Python、Node、SDK 或 .NET，也不加载自研内核驱动。不同 NAT 环境的可达性不能保证；没有可达链路时不以业务中继冒充直连。

回退与验证边界
保留上一版安装包和本机配置备份。需要回退时先停止本机连接，等待资源退出；不要启动第二个占用相同资源的实例。只恢复同一台电脑的 DPAPI 备份。
启用成员平等管理后，旧客户端不能继续验证或管理此网络。回退需恢复升级前备份，并按旧版能力重新组网；不要把旧成员表覆盖到当前服务器数据上。新治理规则不能通过旧根密钥撤销。
本轮完成隔离核心、HTTPS 恢复、浏览器与自包含运行包检查。真实 NAT、大码率串流及免重启 MSI 升级以实机验收为准；历史 MSI 升级返回 3010 的问题不能由本次运行包检查代替。SHA-256 用于完整性校验，不是发布者签名。详细范围见本版交付说明与仓库 docs/aq1/成员平等管理-20261106.md。
