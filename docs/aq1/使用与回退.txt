StreamLink 1.0.1-rc.6 修复候选（AQ-1）

本轮按用户要求完成本机开发与运行包；Thinkbook / Akane 的物理双机质量和本人串流另行验收。请以交付目录的最终结果为准，不能将本机回环或历史 0.3.2 成绩视为本包效果。

1. 两端分别双击本包的 StreamLink-…-x64.msi 安装。较新 MSI 可更新，Windows“已安装的应用”可修复或卸载。如果仍有旧通道，更新不主动切断它；用户此前已卸载的 0.3.2 不会重新安装。
2. 使用日常账号普通打开桌面或开始菜单的 StreamLink。安装的服务是 StreamLink-PersonalFeature，默认源端口 44691、监听 44680；不会选择名为 StreamLink 的旧服务。程序位于安装目录 app 子目录，入口无需依赖旁边铺满 DLL。ZIP 备用包可解压后普通双击顶层 StreamLink.exe；后台安装见“安装与更新”。
3. 已有配对与配置通过 MSI 更新保留，无需重新组网。首次使用在“添加设备”填同一个可用的 HTTPS 协调地址；本次 https://streamlink-personal.space4sgsa.com/ 已于 2026-10-31 恢复，客户端未硬编码它。公开证书通常不填指纹。STUN 为 stun.space4sgsa.com:3478，与协调地址分开。
4. A 创建网络，B 输入 A 的六位码并加入；双方通过可信方式核对校验码，A 点击允许加入。创建/加入完成后自动保存基础增强配置并启动网络。无需另点增强预设。
5. “连接”首页显示设备、虚拟 IP 与连接进度；链路详情默认折叠。复制对端 IP 到 Moonlight 等应用。先低码率确认画面、声音和输入；再进行实际目标码率测试。
6. “设置 → 诊断与日志”可检查准备、导出脱敏状态与日志。50 Mbps / 20 秒测试要求两端在“连接设置”允许手动质量请求；结果为对端→本机方向，90 秒设备冷却保留。测另一方向时改在另一台操作。请求负载与实际提供负载分列；UDP 与 FakeTCP、两个方向分别记录。
7. 浏览器关闭和退出面板不停止服务。需要断网时点击“断开”。设备名称和日志等级热更新；改变端口等设置会明确确认并重建连接。
   MSI 安装后登录自动启动托盘，不弹浏览器；WebUI 固定监听 http://127.0.0.1:47821/，会话过期请从托盘重新打开。
8. 未连接时显示阶段、已等待时间、本轮剩余时间或重试倒计时。无法直连时会继续后台重试。“重新探测”唤醒等待中的探测，不重建健康路径或网卡；每 10 秒最多接受一次。
9. 面板收不到后台状态时会显示“状态未更新”，不能由此推断串流断线。面板活动会续期，空闲 30 分钟或最长 8 小时后需要从托盘重新打开；后台网络继续运行。

协议与独立性
- 正式网卡为官方 Wintun 0.14.1，捕获/注入为 WinDivert 2.2.2。
- 默认业务为 udp2raw 派生 FakeTCP＋明文 HTTP 特征，内层 MeshLink 认证加密；没有 TLS 业务握手，不称为 HTTPS 业务。
- “设置 → 连接设置 → 传输模式”仅提供 FakeTCP＋HTTP（默认）和直接 UDP。两端选择一致；失败只重试所选协议，没有跨协议自动回退。直接 UDP 是同一产品路径，用户选择它时不标为降级。控制使用 HTTPS，不要求 UDP 可以到达协调服务。
- 软件包含本地运行库、原生组件和静态前端；不要求终端安装 Lucky、EasyTier、WSL、Python、Node、SDK 或 .NET。
- 自主映射、SO 和来源学习不保证任意 NAT 都能连通。失败时如实显示，不经服务端或其他成员中继。
- 吞吐是实测接收结果；本地注入 API 接受不能当物理送达，阶段字节数不能跨封装直接相减。

旧研究配置
若个人数据目录含自研网卡选择，后台先把原 DPAPI 文件备份为 profile-before-aq1-*.dpapi，再迁移为官方 Wintun并保持停止。面板会明确提示。研究代码只在源码中归档，不分发或加载研究 SYS，不要求 WDK/Gate。

回退
先在面板断开网络，并等待停止完成。若退出未完成，保留日志，不启动第二个资源 owner。需要回到上一候选时先卸载新版，再使用保留的旧安装包；不要跨机器复制 DPAPI。只有本来仍保留 0.3.2 的机器才能回到其原配对与 IP。没有独立管理保障时不要停旧通道。
若 rc.4 或后续版本已选“直接 UDP”，rc.3 不认识新增 udp-only 字段；回退前在两端设置改回 FakeTCP，或停止服务后用本机 profile-before-fixed-transport-*.dpapi 备份恢复原 profile.dpapi。恢复配置前先保留当前文件，不能跨电脑复制备份。
MSI 安装从 Windows“已安装的应用”或开始菜单卸载入口移除，重新运行 MSI 可修复。ZIP 手工安装才使用管理员 app/StreamLink.exe --uninstall。两种方式都只选择个人实例，保留配置和日志，不删除共享驱动，不卸载原 0.3.2。
服务安装更新采用已验证清单和失败回退。不要跨电脑复制 DPAPI 文件；两端分别配对。

界面与恢复
只提供普通权限 WebUI，旧桌面业务窗口已移除；--desktop 仅兼容映射到普通 WebUI 启动，不再打开管理员界面。
托盘右键只保留“打开 WebUI”“退出”，悬停显示版本、后台状态、设备名和虚拟 IP。关闭浏览器或退出托盘均不停止服务网络；断开请在 WebUI 操作。
后台停止时用 services.msc 启动 StreamLink 个人后台；安装损坏时重新运行 MSI 修复，卸载从 Windows 已安装应用或开始菜单执行。

验收边界
工程候选不是正式发布。八套 Windows 栈、长时间串流、干净系统、跨账户/无人登录冷启动等以最终报告逐项说明。未签名应用的 SHA256 仅验证完整性，不是发布者签名。
本机历史观察到关闭偶尔超过 3 秒目标（约 4 秒）；请等待停止完成再启动，不强行开第二个资源 owner。普通权限发布面板、冷启动首次请求、真实 MSI 更新/失败回退/卸载分别记录证据；本人串流仍需试用确认。其他账户及无人登录冷启动不由同账户测试代替。
