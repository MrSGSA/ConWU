# 已有入口备用协调与域名管理

本次在 1.1.0-preview.2 上追加两个功能，不恢复内置 DDNS，不提供业务中继，不改变 FakeTCP＋HTTP 的默认数据语义。

## 已有入口

连接配置新增 `CoordinatorBackup`，默认关闭。开启时必须是已有入口的直连配置，并填写 HTTPS 协调地址；两端分别保存，主机提供自己的入口来源。纯已有入口和自主打洞的原流程继续保留。

首次配对仍由主机生成同一个六位码。主机将对应的入口、网络、成员和临时密钥承诺签名后发布到协调；从机先尝试已填写来源，失败后查询备用公告并联系新入口。公告带主机签名、短期有效期及网络绑定；协调登记要求网络授权，不能覆盖其他网络的同码记录。查询接口限速，返回内容不包含网络秘密或管理私钥。

服务器返回地址不等于配对完成。原有的临时 ECDH、公钥承诺、双方校验码和主机批准仍是授权流程；备用查询返回的主机、网络和密钥承诺还必须与随后接收的配对授权一致。对刚创建的公告进行短暂有界重查，以处理发布与读取竞态。

已配对网络向备用协调发布加密、签名的地址元数据。主数据身份仍为直接网络，不切换为协调网络。优先尝试已配置入口，未形成健康直连时才读取备用元数据；离线查询有频率上限。备用地址也失败时继续保留原入口重试机会。已有健康连接保持原路径，备用服务异常不影响直接元数据交换。整个模式不创建 STUN、UPnP 或自主打洞资源。

配置修改仍通过共享配置库应用。修改备用开关会重启受影响网络的运行器以正确建立或释放发现客户端，但不改变网络身份。直接加入后的设置保存保留备用地址与证书指纹。

## 域名管理

Linux 显式设置远程管理密码后，协调监听可以将 `/admin/` 委托给同进程的远程 WebPanel。原协调地址和 Cloudflare Tunnel 目标不变，无需另加路径路由；原来的独立回环 47823 也保留。没有远程管理配置时不挂载此入口。

管理入口保留 HTTPS 来源和 Host 校验、密码限速、Secure/HttpOnly/SameSite Cookie、独立会话和 CSRF 校验，不接受本机启动票据。协调授权不能转化为管理授权。未登录访问管理根路径时跳转登录页；通过协调监听进入的管理请求使用同样的请求体上限。关闭远程管理后重启服务即移除入口。

## 检查范围

分开检查正确性／安全和产品／质量；受影响回归包含现有配置库、多网络、协调配对、纯直接短码、入口恢复、Web 会话以及真实浏览器交互。新增回归包含公告篡改、过期和跨网络覆盖拒绝、HTTPS 备用发布／读取、保持直接身份的加密元数据，以及配置入口失败后通过备用地址继续同一码审批并传送数据的完整受控链路。

这些检查使用隔离配置、回环传输与内存网卡，不代表公网 NAT 穿透或 Moonlight 串流效果。实际串流仍由用户测试。工程候选不能因此标记为正式发布全部通过。
