日期：2026-11-08。起点为 `811b344f` / 1.1.0-preview.3。目标候选为 1.1.0-preview.4（MSI 1.1.3）。功能实现和冻结前定向检查已完成；冻结后核心验证与包交付结果记录在候选目录的 `交付与验证.md`。日用实例尚未替换，未发布 GitHub。

## 本轮授权和产品范围

用户已确认第二版 HTML 预览，要求开始功能实现；随后要求加入 PKARR 尝试。保持双机多网络、集中审批、默认 FakeTCP＋HTTP、不自动回退 UDP、不业务中继，不恢复内置 DDNS。真实两机串流由用户测试。

页面按预览接入真实状态：概况设备卡和真实采样图、创建／加入左右并列、网络设置浮窗、已加入设置只读、加入申请和协调独立导航、设备设置三部分、标题右侧保存与草稿状态。

加入仅填写短码或完整邀请。短码通过已保存协调定位；没有可用协调、仍用短码时才补充主机入口。完整邀请携带入口及明确协议。支持协调返回已有入口公告，再向主机直接申请。

批准时通过已有 SAS 绑定的加密通道下发白名单设置。入口归属转换、虚拟 IP 和本机端口资源分离；主机私钥、管理密码、本机启动和日志等不下发。自动加入不挂接本机配置库，直接修改和改配均受后台保护。旧配置引用保留，修改共享设置明确显示影响范围。

PKARR 默认关闭，每网独立发布密钥，密钥与单调序列号保存在受保护网络配置。使用上游 HTTPS 网关和标准 BEP44/Ed25519 签名 DNS TXT 公告；仅包含入口、协议和时效。网关不承载串流，发现成功不视为直连成功。源码依赖 BouncyCastle.Cryptography 2.6.2，许可随包。

- 自动获取设置：直接入口＋短码、HTTPS 配对、已有入口备用协调、审批前不应用设置、只读保护和重启保留订阅已通过隔离回归。
- 既有多网络与配置库定向回归已通过。
- PKARR 协议、签名／过期／旧版本／协议不匹配／网关故障／取消验证已通过；后台发布、每网独立密钥、重启同键重发、地址变更重发、事务回滚保留发布身份、关闭不重建接收器已通过注入网关回归。
- 真实 WebPanel＋隔离后台浏览器回归已通过，包含持久保存、输入不被轮询覆盖、丢弃草稿、配置另存与删除、帮助展开状态、窄屏滚动导航和新资源加载。
- 正式资源配合延迟 API 的浏览器检查通过：保存时锁定对应字段；切页不丢草稿；后台配对读取不占前台忙碌；取消恢复输入；迟到状态不恢复旧申请。
- WebPanel 核心与后台响应性回归通过。Linux x64 托管项目编译通过；既有跨平台分析警告不冒充零警告。新增依赖的 NuGet 漏洞审计未报告已知漏洞，许可随包。

## 两轮分离自查

正确性／安全自查：按审批绑定和加密交付追踪设置白名单；验证未批准不应用、身份／协议不匹配拒绝、直接修改和配置 assign 均不能绕过只读；检查发布私钥不进状态、不下发、不写公告，每网独立且先持久序列号再发送；检查网关验签、大小／时间限制、取消及后台任务退出。定向回归覆盖这些保护边界。

产品／质量自查：对照第二版预览核查导航、布局、真实图表和只读流程；用真实浏览器检查草稿、保存与恢复、配置复用、申请取消和慢请求；查看宽窄屏截图，修复窄屏导航挤压及只改配置名称关闭未提示的问题。说明只解释何时补填主机入口，没有在此塞入连接原理。
