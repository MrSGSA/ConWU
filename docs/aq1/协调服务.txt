此目录是与 Windows 候选对应的 Linux x64 自包含协调服务，未在本轮部署。
现有个人 HTTPS 协调在本轮只读检查支持 Mesh4、Traversal1、8 成员，relay=false；TCP SYN 观察未启用。
运行所需系统依赖是受支持 Linux 的基础运行库。源站可只监听回环 HTTP，由已有 HTTPS 入口保护控制面；业务不经此服务转发。
Native SYN 观察/预约/来源回执和预算的现有源码仍包含在服务中。启用需要独立配置实际本机观察地址与 CAP_NET_RAW，不因此替换旧服务或改公网规则。
部署脚本仅供已有授权下操作；本轮用户选择先完成本机开发与运行包，不部署 Akane 或修改公网设施。
