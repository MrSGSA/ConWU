此目录是与 Windows 1.0.1-rc.8 对应的 Linux x64 自包含协调服务包。
本轮仅构建和隔离验证，未部署或检查公网服务当前版本。

新增能力：/health 提供 pairingDecisions=1 与 meshAddressing=1。
新版 WebUI 创建/加入/邀请先检查 pairingDecisions，保证“拒绝”和“取消”能通知另一端；旧协调服务需要先更新。
自定义虚拟 IP 需要 meshAddressing=1；自定义地址网络的所有成员都应使用 rc.8 或更新版本。
旧默认地址网络、既有配对及端点公告保持兼容，不需要因为界面更新而重新配对。
已有入口仅是端点线索，协调仍负责配对、审批与成员发现；服务不转发业务。

源站可只监听回环 HTTP，由既有 HTTPS/Cloudflare Tunnel 承担控制入口。不得用 Tunnel 承载串流数据。
沿用现有服务的环境变量、监听端口、域名和 TLS 配置。升级前备份旧程序；停止对应协调服务后替换本目录文件，再启动并核验 /health。
stun.space4sgsa.com:3478 是独立 STUN 地址，不能填入 HTTPS 协调栏。
部署脚本保留原来显式指定安装路径和服务名的保护，不应误覆盖其他服务。
官方系统基础运行库仍由受支持的 Linux 环境提供；不需要安装 .NET SDK。
