已检查并实施
1. 普通双击进入托盘与浏览器面板；首次明确安装个人后台。服务拥有网络资源，浏览器关闭不停止网络。管理员桌面入口 --desktop 用于恢复。
2. 页面覆盖总览、逐成员链路、创建/加入/身份批准、连接偏好、端口与显式入口、手动质量许可、诊断导出、名称与日志。新建/加入复用自动增强预设与启动，不要求用户手动拼装内部 Harness。
3. 设备页仅确认本机到成员的链路，其他边未知。UDP 直连与质量分别展示；不将每个 UDP 结果标为不可用，不显示“已绕过 QoS”。
4. 配置轮询保留草稿，冲突不覆盖；需要重建网络的设置明确确认。UI 显示实际版本、承载、建链、未知质量和错误。
5. 静态前端随自包含 Web 宿主打包，终端不需要 Node/npm/.NET/WSL。默认使用官方驱动，无研究 Gate。
6. 质量结果包含请求负载、成功发送 API 对应负载、唯一接收、重复、乱序与收尾窗口。诊断附 Wintun、队列、显式 worker 的原始汇总与路由见证；不跨不同封装长度直接相减。
7. 页面经真实无头 Edge 检查，包含桌面/390px、深浅色、键盘、空态/错误态、保存与刷新。截图仅为本机产品流程证据，非实际串流证据。
8. 原 0.3.2、DPAPI 配置和管理路径保留。包内提供安装与最短回退说明；实际安装/恢复只使用唯一验证实例。
