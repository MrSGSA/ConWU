# ConWU 收敛版两轮自查

执行者：Sol 单代理。两轮由同一执行者分开完成，属于自查，不冒称外部独立审计。构包、安装和 Linux 包验证的最终结果另见交付记录。

## 第一轮：正确性与安全

检查配置持久化、共享引用、权限、入口解析、配对、并发保存及资源归属。

已修正的问题：

- 共享保存不能只更新当前网络：配置具有独立 ID／版本，所有引用者都参与校验和应用；中断应用时保留目标版本和逐网状态，重启后补齐。
- 多网络改端口时，旧共享接收器必须先释放全部受影响消费者，再打开新接收器。源端口分别分配，不更换用户公布的接收端口。
- 删除后的迟到状态请求返回完整工作区，避免被误报成后台失联。过期的已删除网络操作索引有界清理。
- 自主模式中保存的旧入口继续保留，但不会被恢复成活动入口；已有入口不启动自主 STUN、映射或候选工厂。
- 短码连接给每个候选单独设置期限，首个入口不响应时继续检查后续入口；总期限有界。
- TXT／HTTPS 标签精确匹配，缺少标签不选择其他主机；标签与完整含读取凭据的 URL 分别进入缓存键。
- 内置 DNS 写入客户端、发布任务、专用记录和短码索引从产品移除。旧敏感设置先受保护备份，再从活动配置移除；维护读取不写迁移数据。
- 共用配置不保存网络密钥、成员或实际虚拟 IP。虚拟地址偏好按网络保存；退出、复制及升级不会合并身份。
- 保留本机控制授权、操作 ID、防重放、CSRF、Host／Origin、响应大小和配置库容量限制。远程管理使用单独监听、密码哈希和受限 Cookie，不借协调权限管理本机。

证据：配置库及迁移定向检查、双机多网络受控通信、真实回环 HTTPS 协调中断、严格已有入口、Web 会话与远程管理认证检查。受影响部分均在修改后重新验证，最终冻结核心验证另留记录。

## 第二轮：产品与质量

以 1.0.5 实际 HTML/CSS/JS 为基准检查常用操作、配置作用范围、草稿、反馈和故障恢复。

已修正的问题：

- 新配置在轮询时被自动切回旧配置，导致名称和输入丢失。
- 分区／页面切换触发旧页面的增量刷新分支，造成控件缺失或输入不可用。
- 本机设置与连接配置之间切换丢草稿，日志设置链接进入错误范围。
- 折叠状态使用新页面名称记忆旧页面，返回后自动收起。
- 新配置没有保存却显示“已保存”；名称修改未计入保存提醒。
- 多网络申请列表的第一个同意按钮依赖当前选中网络，导致错误禁用；审批现在绑定各自目标网络。
- 概况入口缺失时显示 `Unknown`，以及入站端口错误取自当前配置。现在显示可解释的认证目标或本网络入站端口。
- 手动切换页面影响实时流量采样；直连计时补齐秒，并优先使用后端连接时长。
- CLI 帮助和构包说明仍引导设备全局连接设置及 DDNS；已与新配置库和直接短码流程一致。

浏览器检查使用真实 WebPanel、受限 IPC 和隔离后台，覆盖保存、切换、输入、轮询、撤销、作用范围及审批按钮。预览单独标明示例数据，不把静态页面当运行证据。

## 验证边界

本轮不进行公网两机、吞吐、压力或 Moonlight 长时间串流测试。自主无协调邀请只证明能够携带取得的候选，不保证严格 NAT 可穿透。固定地址变化后仍需人工更新，只有 ID 和密钥不能推导新地址。

保留默认 FakeTCP＋HTTP、手动固定协议、官方 Wintun／WinDivert、无业务中继和无网络间转发。Linux 为 x64／glibc 候选；其他发行版和架构的实际兼容性不作扩大声明。
