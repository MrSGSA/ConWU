# StreamLink 1.0.0-rc1 本轮完成度与发布判断

本轮交付 **开发 RC，不是 1.0 正式版**。保留 Wintun→MeshLink→udp2raw FakeTCP+HTTP 已有数据面、SO、来源学习、共同提名和 UDP 唯一同 socket 架构。HTTP 特征是既有明文前导，不宣称新增真实 TLS；业务禁止服务器/成员中继，外层无业务重传和数据报顺序等待，默认 PreferFakeTcp 保护健康 Active。

执行依据是 `docs/review-1.0/` 的固定 3b285f2 执行/源码审查/32任务交接；基线3b285f25a0cbe7949a33bfb6c0c323e3f7423fa0。代码候选1e7928e4868e93919417330eede62d9896de8d99，最终固定包与文档提交在交付索引单独记录。没有重写交接规格或改变原 Gate。

## 本轮实际完成

- SEC-01 修复完整生产 TCP 解析器的长度、doff/options、错误返回和输出清零契约；补 checksum/分片处理与原生/managed共同语料。29659原生断言含20000 mutation，22414帧比较零差异；完整链接 Linux ASan/UBSan通过。HTTP/bare/SEQ行为保留。
- 控制操作 ID、重复请求处理、只读状态、取消旁路与有界退出；未完成的资源所有权不会因界面超时被释放后重开第二实例。旧 Quality 升级认证 v2、接收端许可、共享90秒冷却/总预算/远端取消/故障隔离。
- 元数据热保存、未知 JSON 字段和用户明确禁用/旧版未知意图保留；STUN 列表用于后续新尝试，保存不关闭 Active。其他网络字段仍有明确重建提示，不能称全部细粒度热迁移已完成。
- 兼容业务出口通道接到正式 Runner 共享 pacing：有界原生交接、实际父进程回执、过载计账、capture fence、实际路由见证与迟到准备取消。独立开关默认关闭，真实最终 WinDivert注入/物理出口/负载 A-B Gate仍缺。
- 私网 UDP 生产采集器可从同一持有 socket 做4训练+2后续holdout，并以独立能力/开关协商经验证据；真实声明对端端口见证通过 epoch资源包装器接线。42项本轮测试中有真实 Windows STUN/认证回应与完整 UDP/MeshLink业务；NAT/过滤仍区分夹具，不宣称校园网新增覆盖。经验EIM不能替代完整对端端口范围强证据。
- 界面总览/设备/诊断/设置、创建/加入二级流程、进行中/灰化/取消反馈和动态DPI；实际250%六页渲染28项通过。asInvoker日常受限UI与管理员管理分离，独立SID管道仅脱敏DTO/白名单补丁；原完整管道没有开放给Users。
- 扩展既有IPacketAdapter，不另造同义抽象：provider/ABI、取消、MTU、统计、真实前缀/路由冲突及警告。官方适配器增加读写/统计/取消与释放的并发保护；当前1073项Mesh回归含实际Windows UDP→Wintun→MeshLink→原套接字返回以及清理。
- 原创最小NDIS raw-IPv4 TUN、用户DLL、独立研究provider、buffered I/O/资源边界；独立有界WFP观察样机。MSVC/WDK编译、INF验证和8项真实用户ABI/无效句柄测试通过。研究SYS未签名、未加载；WFP实际注入仍未实现，默认官方驱动不变。
- 统一1.0.0-rc1 SemVer及正式/预览更新通道；完整运行包预检、必需组件、x64/ABI/hash、SBOM/许可/同提交源码。原生内置PolarSSL代码的GPL头与libev许可已单独保留，不能把整个二进制只标MIT。

## 默认能力与遗留代码

详见 `capability-decisions.json`。继承默认FakeTCP显式入口、PreferFakeTcp、官方驱动和Mesh认证/禁止转发；默认启用安全解析与控制/保存修复。SO、来源学习、预测、概率探索、经验EIM、兼容pacing、诊断自动选路与IPv6/网关增强逐项有开关/能力/证据，不因版本号自动全开。已明确禁用的意图不能被升级改变。

代码仍Partial的主要项：细粒度per-peer网络设置迁移；完整私网授权多端口强provider；普通用户全流程/高级配对权限分离；完整输入与依赖来源审查；可信发布者签名验证；WFP实际注入接口；自研TUN内核实机正确性。它们没有被包装成已完成接口或已通过驱动。

## 阻塞与发布判断

Akane本轮只读SSH检查超时，不无限重复。缺真实校园网NAT4与独立可控NAT/外部观测、双公网IP设施、两个原生互联网IPv6端点、实际PCP/NAT-PMP网关、八台Windows、混合DPI显示器、真实非提升/跨用户上下文、未登录启动/恢复，以及独立可恢复驱动实验机/签名账户。逐任务最高阶段与具体缺项见32项状态账本；人工步骤与原门槛见 `manual-acceptance.md`。

推荐交付等级：**1.0.0-rc1 开发/审查候选**。当前条件不允许发布1.0稳定标签或宣称新增公网NAT4覆盖、零丢50Mbps、八机/自研驱动正式可用。保留现有已工作的软件；候选替换会中断本软件连接，生产切换需按人工验收先形成具体结果。服务器协调包仅准备、未部署；没有修改安全中心、驱动签名策略、VMware、网卡offload或生产网络。

安装/回滚仅清自有服务、目录、规则、地址，不卸载共享驱动。回滚保留最新撤销目录/授权状态，不通过旧备份抹去已知撤销。最终交付索引固定包hash、完整源码、研究驱动产物、各测试范围/失败和Git提交范围；本轮在这些当前可执行交付完成后结束，不宣称缺失Gate已经完成。
