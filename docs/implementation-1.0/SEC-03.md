# 会话、撤销与输出边界

保留既有 MeshLink 密码协议及每成员单一逻辑会话。方向密钥由共享秘密、随机发送epoch、from/to派生；同会话的业务/控制共同分配单调64bit序号作为nonce。新旧承载共用相同MeshLink和重放状态，换进程/退休epoch仍使用原有新密钥挑战，不重写密码协议。

本轮增加并发业务/控制1024个实际加密帧，检查同一方向密钥下的实际epoch/nonce唯一、完整认证和同密文重放拒绝；既有乱序立即交付、丢包无队头等待、假源IP、禁止成员转发及70次会话重建回归继续通过。完整MeshTests1066断言，但不将数量当公网、多设备或内核验证覆盖。

ProfileStore新增同网络/OwnerKey的持久化撤销revision保护：低revision拒绝，同revision签名冲突拒绝；重新导入缺目录的旧邀请继承本机已知最新目录，不丢失撤销记录。后台日志与Error统一去除当前共享秘密、外层RawKey、成员/Owner私钥和完整SL邀请；超时则不输出原文。只读导出继续字段白名单。

真实本机Windows DPAPI/Worker/UI回归106项通过，增加了实际日志脱敏、同网保存回退拒绝及旧邀请导入保持撤销。没有修改当前运行服务。

当前仍是创建者产生成员私钥的既有模型，没有前向保密承诺；本轮未把这些历史限制改写为已解决。普通权限UI还需独立脱敏DTO、指定SID和受限方法，绝不能开放旧完整Profile/Invite管道。多机迁移、协调离线撤销时效、真实Candidate/Active并存及固定安装包回滚仍须继续验收。
