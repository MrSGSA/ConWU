# UI-01 / UI-03：界面结构与动态 DPI

本次沿用 WinForms 和现有配对协议。一级导航改为总览、设备、诊断、设置，创建与加入留在次级页面。总览显示本机直连成员数，不把服务运行等同于全网连通；设备页面保留复制 IP 与明确移除，按文字变化增量更新。只读诊断导出采用字段白名单，不序列化 Profile 或原始 ControlReply。测速说明对端许可、20 秒上限和 90 秒冷却。

操作期间禁用冲突按钮，显示阶段和取消等待；状态查询不再被界面写操作门锁阻塞。主动配对请求使用操作取消令牌，清理已创建房间仍使用独立三秒期限。取消批准不会默默撤销可能已送达的邀请。

动态生成的页面、设备行按当前 DPI 缩放一次；初始控件由窗体缩放，避免嵌套自动缩放导致空白页面。窗口限制到当前屏幕工作区。高级设置使用滚动正文和固定保存/取消区，设置 PerMonitorV2。

## 本轮证据

- 本机 Windows 实际 DPI 240（250%）。真实 WinForms 程序预览模式渲染六页：28 项检查通过，包括非空页面、按钮尺寸、工作区、滚动回位和完整重绘一致性。
- 32 次离屏绘制：中位 28.9995ms，p95 36.2271ms。此值不是屏幕帧率或物理显示残影测量。
- 重编译 WindowsTests：103 项通过，包括忙碌/成功/失败反馈与设置意图恢复；未更改当前服务或网络。
- 保留反射夹具错误、DPI 宿主空白及动态行未缩放的失败日志，不用最终成功覆盖失败证据。
