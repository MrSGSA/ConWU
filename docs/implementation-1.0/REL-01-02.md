# 固定RC版本、更新与安装边界

目标通过 Directory.Build.targets统一为1.0.0-rc1，Assembly/FileVersion1.0.0.0，InformationalVersion保持SemVer及可选源码元数据。发布版本不再把所有预发布后缀拆掉比较。正式更新通道排除RC/preview及draft，预览通道显式选择；数字prerelease按数值优先级比较，build metadata不改变优先级。当前旧Package.ps1仍是历史0.5.x工作流，**不能用它直接伪装RC交付**，新固定包流程待完成。

公开验包入口要求schema2、win-x64、MeshLink4/TUN ABI2、13个必需运行文件与原有安全路径/哈希检查，检查宿主及原生组件PE x64头。缺一个组件后自行重算hash也拒绝。自列hash只证明完整性，不证明来源；目前只能声明UnsignedCandidate，自声明VerifiedPublisher拒绝。签名账户/可信发布者验证未完成，正式来源Gate不通过。

安装先公开验包，再复制到受管目录。新的后台只有初始化完成且本地受保护status接口可用、版本/控制能力匹配才返回ServiceReady。对端离线或没有公网直连不作为安装失败条件。候选失败会恢复旧服务路径与授权SID；首次失败清理本次服务注册；双失败明确报告，不吞异常。**实际系统服务安装事务尚未在本轮执行或验证。** 旧服务恢复健康、重复安装、授权恢复失败等场景还需扩大隔离测试。

已跑Core41（包含6个SemVer新增例）Pass、Windows109项Pass（包含必需集合/伪来源/UTF8 BOM，运行组件用明确合成PE夹具）、Control21项Pass。合成PE夹具不是可执行文件签名/ABI实测；现有Core接口版本判断不依赖SemVer猜能力。
