# StreamLink 0.5.3-preview 开发候选

保留 Wintun → MeshLink → udp2raw FakeTCP＋HTTP 和默认优先 FakeTCP；业务继续双端直连，不经协调服务器或其他成员中继。此版本为默认保守的开发预览，整体发布验收保持 `NotPassed`。

## 相对 0.5.2

- UDP 多源探索接入独立能力、双方签名候选、正式 Factory/Runner 和设置。原观察 socket 延续到业务；共享 12 秒期限、全机预算和 TCP/UDP 高成本名额，未获胜资源准确释放。
- 探索默认关闭。生产自动稳定资格目前只批准经同源独立目标观察的物理原生公网 IPv4；普通私网源不能因为多个 STUN 返回同端点就获得概率试探资格。私网 peer-port 观察设施仍待完成，旧端/旧服务保留普通流程。
- paced UDP 不再叠加前置 128 包队列，出口满时立即反馈拒绝；未 pacing 的 UDP 将在途包纳入有界内存。瞬时压力丢当前数据报，无业务重传；明确致命源错误向路径报告。
- 正式成员/路径状态和 Runner 日志增加本地发送账本、在途字节、容量拒绝、挤出、取消、发送失败和当前队列年龄。Sent 是本地发送回调成功，不代表对端收到，也不是完整系统网卡审计。

## 验证范围

打包前的 UDP 探索记录包括 90 个本地正式接入案例（模型与 Windows UDP 回环），最后准入/签名/旧能力回归；队列记录包括 61 项持续调度、129 项正式 Runner、673 项普通 UDP/Router 检查。单/七合成成员各 20 秒调度约 49.912/49.903 Mbps，原本地 98% 门槛不变。

模型资格、受控 NAT、raw/IP 适配器、真实回环 socket 与真实公网证据分别记录。没有将本地 90/90 或吞吐写成严格 NAT 成功率；原始 seed 密钥和取消计账失败产物均保留。完整 Package 和实际包核验以随包构建来源/验证摘要及后续候选收据为准。

## 默认与限制

默认保留兼容入口、FakeTCP＋HTTP、MeshLink/Wintun、FakeTCP 优先、恢复诊断。SO、UDP 降级、TCP 观察/校准/预测/来源学习、UDP 探索、PCP/NAT-PMP、IPv6、pacing 不因升级自动开启。AutoQuality 暂不可启用。

仍需完成私网探索证据、方向性负载/AutoQuality、兼容及多物理出口完整队列/账本、系统恢复，以及公网/真实 PMTU、八台 Windows、60 分钟质量、实际安装/升级/回滚 Gate。不存在没有直连时自动启用业务中继的路径。

## 使用和回退

运行完整解压目录中的前台；后台安装/升级仍由设置中的服务操作触发。交付和只读包核验不替换现用服务或升级协调服务器。探索需要双方及服务能力，单机勾选不能绕过资格。

关闭实验并保存可回普通候选；pacing 设 0 关闭。整包回退先停止候选网络并确认资源退出，再通过旧完整包恢复服务及配置备份，保留旧目录；不删除共享驱动、无关网络配置，也不回退成员撤销目录。0.5.2/0.5.1/0.5.0 包继续保留。

产品 EXE 未代码签名。包内清单核对完整性，可信发布渠道与依赖许可证仍分别遵循；实际安装和回滚不能由临时目录测试代替。
