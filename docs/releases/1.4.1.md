# ConWU 1.4.1

本版调整日志与直连码管理，保留现有网络、设置、协议及身份。

- 创建网络始终保留左侧的新建表单。右侧每个网络的“查看直连码”打开独立弹窗，顶部显示对应网络名称；生成、重新生成和复制均绑定该网络。关闭、切换弹窗或异步返回不会覆盖其他网络或新建草稿，生成错误直接显示在弹窗内。
- 日志一行显示一条记录，长内容在终端内横向滚动，时间与等级前缀保持完整。记录内部换行用 `↵` 展示；后台刷新保留横向位置，搜索、筛选和复制继续可用。不增加定时日志或额外的同步状态展示。
- 修复“仅使用已有入口”的正常启动说明被误标为 WARN。没有已验证路径时，不再错误提示“保留已有路径”；候选传输准备或失败日志包含具体目标入口。
- 修复网卡准备较慢时，第一次连接可能跳过优先候选、先尝试旧地址的问题。直连候选轮询现在从该设备实际开始选址时计时，来源变化后重新从第一项开始，不再把后台启动耗时计入候选尝试时间。
- 入口日志明确区分 DNS 查询候选与当前已验证的实际直连，标注系统 DNS 来源。上游解析器缓存不一致时可能返回旧候选，已验证连接继续保留，不启动自主打洞或协议回退。
- 修复 Windows 下 Linux 打包时父目录路径分隔符的处理。

已通过真实 WebUI 的创建表单、独立弹窗、多网络异步操作、日志刷新与布局回归，以及隔离的 TXT 恢复和重启复连检查。三机升级及附件校验范围见验证附件；手机和 Moonlight 实际串流不属于本次自动验收。

关于早期性能测试：用户已反馈 Mimic 实际 40 Mbps 串流正常，其自主打洞也正常，Phantun 实际串流同样正常。之前独立合成测试的接收缺口仅表示该测试未通过，不能直接认定为协议、物理线路或运营商限制。头部观测器原先使用 100 ms 队列期限，且没有自身漏捕统计；本版提高观测队列余量并明确标注证据边界，后续先校准测试工具再做同条件对照。原始历史数据保留，Mimic／TCPRAW 的实验标记继续保留。

正式附件提供 Windows x64 与 Linux x64；Android 继续使用独立测试版本，本版不提供新的 Android 正式安装包。
