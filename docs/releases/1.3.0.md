# ConWU 1.3.0

本版修复旧 DNS 缓存引起的长时间复连，完善主机端口映射，并增加可选的 Mimic、TCPRAW 实验协议。默认继续使用 FakeTCP＋HTTP，现有网络不会自动更换协议。

- 已配对设备启动或断线后，TXT 入口可通过系统 DNS 与多个 HTTPS DNS 后端补充查询；保留各来源候选，继续执行原有身份认证。健康连接使用普通查询，不修改整机 DNS。离线重试暂停最长 30 秒，地址改变会立即唤醒。
- 自主打洞优先申请独立 UPnP 短期租约，处理外部端口占用、续租失败、规则丢失和地址变化。端口设置可启用 PCP/NAT-PMP 后备；已有入口模式继续由用户的转发或第三方工具维护，不自行抢占映射。NAT1 等厂商选项仍需在路由器中设置。
- 新增 **Mimic（实验）** 和 **TCPRAW（实验）**。Mimic 实现数据报 TCP 报文转换，TCPRAW 通过系统 TCP 握手后改用原始 TCP 报文传输；两者均不把业务写入可靠 TCP 字节流。Windows 使用现有 WinDivert，Linux 使用原始 IPv4 收发，不增加新驱动。
- 纳入 Phantun 承载及 TCP/HTTPS 可选的按流分离连接；不同数据流可使用独立连接，减轻视频流对音频和控制的影响。分离连接默认关闭，对端不支持时使用主连接；不保证提高视频吞吐。
- 新协议沿用 16 位直连码、主机审批、自动配置继承、端到端加密和防重放。多网络共享监听保持隔离，退出一个网络不会拆掉其他网络的接收器。

Windows x64 推荐下载 MSI；完整 ZIP 便于检查和维护。Linux x86_64/glibc 下载 tar.gz 后运行 `sudo ./install.sh`。Windows 安装器内部版本为 **1.3.1**，用于从 1.3.0-preview.1 正常升级。

请两端一起更新。更新保留设置、网络、虚拟 IP、设备身份和证书。选择 Mimic、TCPRAW 等不同协议时需要新建网络并重新配对；原网络继续使用已选协议。每个接收端口只共享同一协议，不增加业务中继或自动 UDP 回退。

Mimic/TCPRAW 已通过 Linux 隔离环境中的完整审批、配置继承、双向报文、重连和多网络隔离，以及 Windows/Linux 分别担任主机的四组 35 Mbps 合成流量互通。它们仍是实验选项，不预设优于 FakeTCP/Phantun，也不代表已通过上游二进制互通或实际 Moonlight 验收。完整 1280 字节虚拟 IP 报文需要至少 1404 字节外层 IPv4 MTU，TCPRAW 含时间戳时需要 1416 字节；本版未新增原始 IP 分片。

随附 verification.json 记录构建、安装与设置继承的验证范围。真实 NAT、休眠和串流体验由实机继续验收。应用程序未进行发布者签名；官方驱动的签名和固定哈希在构建时检查。

附件包含 Windows/Linux 程序、对应源码、许可证、SBOM、SHA256 与验证摘要。可选的 Mimic/TCPRAW 原生进程使用 GPL-2.0-only，主程序保留 MIT 许可证。
