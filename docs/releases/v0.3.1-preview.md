StreamLink 0.3.1 修复设置页上下滚动时的卡顿与旧画面残留。

- 渐变背景按窗口像素尺寸缓存，窗口大小或 DPI 改变时才重建。
- 滚动区域改为不透明底色，保留外围彩白渐变，避免多层透明控件反复绘制大背景。
- 滚动区域单独缓冲并合成子控件；滚轮及滚动条拖动后异步标记整个可见区重绘，避免保留滚动前的局部像素。没有在滚动消息里强制同步刷新整个窗口。
- 切换页面重置滚动位置。版本号、更新检查和安装清单校验统一读取桌面程序集版本。

验证：240 DPI、2114×1389 像素设置页、32 次滚动加离屏绘制；中位耗时从 159.64 ms 降至 36.18 ms，约减少 77.3%，P95 从 180.14 ms 降至 42.32 ms。离屏绘制耗时不是屏幕 FPS，也不能替代用户在实际显示器上确认残影是否消失。9 项绘制回归和 23 项 Windows 生命周期/界面操作检查通过。

此版仅修改桌面绘制及打包版本管理，传输、配对和后台连接逻辑未改。完整包保留已验证的原生 udp2raw 和 EasyTier 二进制。未停止或更新当前正在运行的后台服务，没有进行新的公网吞吐测试。

升级：解压到新目录，退出旧界面后启动新版 StreamLink.exe。**已经使用后台服务时，不需要更新、卸载或重装服务，也不需要重新配对。** 若当前为前台模式，退出程序会短暂断开，重新打开后按原状态恢复。旧包保留可回退；不要同时运行两个界面。

实现依据：WinForms 的透明控件将背景绘制交给父控件（[微软说明](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/controls/how-to-give-your-control-a-transparent-background)）；滚轮路径直接改变显示区域，并不经过 OnScroll（[ScrollableControl 源码](https://source.dot.net/System.Windows.Forms/System/Windows/Forms/Scrolling/ScrollableControl.cs.html)）。只给 OnScroll 加刷新会遗漏鼠标滚轮。局部子控件合成使用 [WS_EX_COMPOSITED](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles)，范围限制在滚动视口。
