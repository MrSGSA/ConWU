StreamLink 0.3.2 优先缩短连接等待，并增加启动阶段计时。

- 选定公网入口后立即通知对端，两端组件可同时初始化；网卡初始化不再阻塞地址公告。
- 未连接时每 2.5 秒协商，已连接时保持 5 秒；界面连接中的本地状态刷新缩短到 750 ms。
- 路由器发现收到可用响应后立即尝试映射，不再固定等满 SSDP 搜索窗口；首个候选失败时继续尝试已收到的其他候选。
- 修正 EasyTier 配置中的网卡名称位置，按网络和设备槽位固定名称，并关闭组网组件不需要的内部 STUN。
- 修正长时间连接后短暂断线可能立即触发重建的问题，补齐 STUN、路由器、组件、网卡与握手的分阶段计时。

保持现有原生 udp2raw、EasyTier 二进制及配对协议。本版尚未实现多机、自主 Wintun 后端或新增页面动效。固定网卡名称不等于持久复用网卡；Windows 网卡与防火墙初始化仍可能占用数十秒。

隔离检查：19 项连接调度、13 项路由器发现/真实配置解析、36 项配对、23 项 Windows 生命周期、9 项绘制检查通过。

2026-10-10 双端实测：

- 同一 Thinkbook 单端服务重启：旧版 56.259 秒，新版 52.343 秒。均从发起服务重启计时到后台报告直连，包含停止时间；各一次，不能当作统计性提速结论或电脑冷启动成绩。
- 新版 Akane → Thinkbook，50 Mbps、20 秒：104142/104142 包，49.98816 Mbps，零丢包；结束时 RTT 单次采样 14.95 ms。
- 两端都已升级并恢复连接，保留配对及虚拟地址；临时升级与回退计划任务已删除。原 Lucky、原 EasyTier 配置、默认路由和 DNS 没有修改。

剩余主要等待：Thinkbook 的组网进程启动到虚拟 IP 就绪约 31.9–36.4 秒，Akane 约 2.37 秒；该阶段包含网卡/防火墙初始化及本机状态查询。只读盘点发现 Thinkbook 有 2841 条 EasyTier 防火墙规则、85 个网络接口，可能影响初始化，但没有通过删除规则对照来证明因果。没有批量清理历史网卡或规则。后续重点是按来源核实历史状态、避免规则持续增长，并拆分虚拟网卡与传输重连生命周期。

固定名称对照并未证明网卡可持久复用或显著提速；模拟 SSDP 首个响应约 45 ms 仅证明不再等待搜索窗口，与公网打洞耗时不同。未验证重启电脑未登录、休眠换网、长期稳定性和重连 P95。完整分析见 `docs/演进路线与连接启动分析.md`。

升级需要在两端设置中点击“更新后台服务”，仅打开新版界面不会替换已安装的后台。更新会短暂中断连接，保留配对与虚拟 IP。前台模式退出旧版再启动新版。保留 0.3.1 完整包，需要回退时从旧包运行 `StreamLink.exe --install`，无需重新配对；不要同时运行两个前台网络。
