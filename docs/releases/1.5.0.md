# ConWU 1.5.0

这一版将 ConWU 的主程序和组网核心迁至 Rust，继续沿用熟悉的界面、直连码和主机审批流程。Windows、Linux 运行主程序不再需要 .NET；六种承载协议及各自的原生组件继续保留，不需要为了升级重新创建网络。

升级会导入原有设备身份、配对关系、网络设置、虚拟 IP、PKARR 身份与协调资料。每个网络仍独立保存配置，断开连接与退出并删除网络也保持原有区别。Windows 还兼容原版的网卡所有权记录，避免切换版本时把自己的残留接口误判为地址冲突。

本次保留并验证了这些连接能力：

- FakeTCP＋HTTP、Phantun、Mimic、TCPRAW、纯 TCP、HTTPS 的配对、真实虚拟网卡双向通信、断开重连和重启恢复。TCP／HTTPS 保留多连接分流，原始承载继续按数据报工作。
- 已有入口与可更新订阅、PKARR 重连发现、可选协调辅助，以及 PCP／NAT-PMP／UPnP 自有端口映射。订阅失败时不会重新使用已经过时的首次入口。
- Windows Mimic 默认使用 WinDivert，处理入站报文、内核 RST 抑制及同端口 STUN 放行；修复部分 WLAN 的 XDP 队列绑定反复失败后无法使用的问题。XDP 保留为显式开发选项，启动失败可回退，安装不再强制重绑 XDP。协议处理仍在用户态，不据此承诺串流性能提升。
- TCP／HTTPS 新增 IPv6 外层连接与 36 位 IPv6 直连码；默认优先使用 IPv4 的 16 位码，出码窗口可明确选择入口类型并显示实际类型。已有入口也注明各协议的 IPv4／IPv6 支持范围。IPv6 已通过隔离双栈环境的真实 TUN 配对和双向通信，公网双栈和另外四种承载的 IPv6 不在本次验证范围内。

更新流程也做了补全。Windows 完整 MSI 会保存上一版程序、设置和安装维护源，安装完成后检查后台与启用的网卡；失败候选可恢复到旧程序。普通用户可以打开服务界面及启动后台，无需开放私密数据目录。Linux 包现在附带 `install.sh` 和 `uninstall.sh`，沿用 `streamlink.service`，更新在独立 systemd 任务中完成，避免旧后台退出时连带杀掉安装进程。两端回退都保留已提交的撤销状态和 PKARR 序号，避免把安全状态退回旧值。

UU 远程继续自动匹配已直连网络，修正“功能开启却显示不支持”的状态兼容问题，网络列表只显示获批网络。规则已就绪和检测到实际持续流量分开显示，进程或网络变化后重建规则、重新确认流量，失败采用有界退避。保留官方进程识别限制，并修复路径分隔符比较导致进程未被识别的问题。

加入失败留下的记录改为单独显示的未完成申请，可直接移除。主机同意或拒绝后，申请卡片和角标立即收尾；配置交付与确认仍在后台完成。更新成功提示支持手动关闭并自动收起，后台运行期间也会读取更新程序稍后写入的完成结果；历史安装和回退资料继续保留。

高级协调路径进一步固定 STUN 观察的源 IP 和端口，过期调度可有界重新同步；已配对建连按轮次去重并预留同源资源，断线会立即唤醒发现任务。操作完成标记与状态快照的读取顺序也已修正，避免操作已经完成却返回中间状态。

TXT 入口检查失败时保留原有提示，补充“或请检查#标签名”；标签仍由用户自行填写。

首次加入网络时，本机承载组件还没启动完成，界面会显示“正在联系主机”；收到双方校验码后再进入等待主机批准。组件启动失败会直接显示原因并写入日志，不再转入无关的 STUN 等待。承载启动与首次配对均有可取消的等待预算。

Windows 默认路径检查官方 WinDivert；XDP 队列检查保留为开发诊断工具。托盘补上了任务栏重建后的图标恢复。开发实网测试还会检查正在活动的日用 UU 会话，避免在串流中重建测试网卡。

日志和概览自动刷新不再打断鼠标选中的文字，输入框与弹窗内的选区同样保留。选中文字时后台继续接收状态，新加入申请的计数仍会更新；取消选择后再补上画面，日志没有变化时也不再反复重建。概览的心跳延迟只统计每轮首次回复，避免把重试间隔算成网络延迟。

此次还修复了原生组件和 Windows Installer 不接受部分规范化路径的问题，保留安装日志及实际错误码；后台关闭会等待网卡、监听和承载进程释放。Windows 重新创建网卡时仍可能等待系统缓存释放，因此不承诺所有设备都能立即恢复连接。

升级保留当前版本与一份完整上一版。Linux 新程序位于 `/opt/conwu/current`，数据位于 `/var/lib/conwu`；首次升级会只读导入旧数据。原目录和 Windows 的部分历史服务、路径名称为兼容升级继续保留，请不要手动删除共享驱动、安装维护源或网卡所有权记录。

本版不宣称解决校园网严格 NAT 的无入口穿透，也没有将微基准提升当作串流速度提升。Android／iOS 不在这次迁移发布范围内，原 APK 不变。安装包对应的验收范围与三机试切结果见随附的 `verification.json`。

生日碰撞已提供默认关闭的独立 TCP 实验程序，尚未接入产品默认或高级模式。缩小端口空间的隔离结果只用于研究一端稳定与双端随机映射的差别，不作为公网成功率。
