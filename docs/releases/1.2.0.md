# ConWU 1.2.0

这版增加纯 TCP 和 HTTPS 通道，补齐入口恢复、后台状态和日志显示。默认仍是 FakeTCP＋HTTP，首次连接继续使用 16 位直连码。

- 新增纯 TCP、TLS＋WebSocket HTTPS 承载。主机准备入口，从机主动连接，同一通道支持双向通信；HTTPS 使用配对批准时绑定的持久公钥指纹。
- 设备重启或入口变化后，自动重新查询保存的订阅。已配对但未连接时，来源检查间隔最长 30 秒；Windows TXT 查询绕过本机答案缓存，仍使用系统 DNS。
- TCP/HTTPS 初次发现遇到无响应的 STUN 服务时，受限尝试后续配置；切换前释放落选连接，保留接收端口。观察失败与网关租约分别维护。
- 修复加入期间误报后台失联、慢状态回复和多网络日志不更新；日志统一显示本机与各网络的消息。
- “对外协调”独立展示本机服务设置与近期已验证客户端；托盘简化为打开 WebUI 和退出托盘。
- 优化 TCP 帧解析、HTTPS 批处理和网络封装的内存分配，兼容已有的单数据报 HTTPS 对端。收益以实际网络和串流体验为准。

Windows x64 下载 `.msi`，Linux x86_64 / glibc 下载 `.tar.gz` 后运行 `sudo ./install.sh`。Windows ZIP 提供完整文件包，日常安装推荐 MSI。Windows 安装器内部版本为 `1.2.3`。

请两端一起更新。当前双机多网络版本的设置、网络身份和证书原样继承；原有 FakeTCP 网络无需重建。选择新增 TCP/HTTPS 协议时需要另建网络，旧网络不会自动切换协议。早期单网络格式仍需按提示重新建立。

已有入口仅使用用户配置的地址或订阅，不触发自主打洞。自主打洞仍受 NAT 条件约束，真实 TCP 双端同时打开尚未实现。本版没有业务中继、内置 DDNS 或自动 UDP 回退。

已完成 Windows TCP/HTTPS 130 项、Linux 105 项及真实 C++ FakeTCP＋HTTP 多网络回环 34 项检查，并补充重启入口恢复回归。正式包的安装、设置继承、服务与页面检查结果见随附验证文件。回环和管理链路测试不代表公网抗 QoS 或 Moonlight 串流验收；实际串流由用户测试。应用安装包尚未进行发布者签名，官方驱动的签名与固定哈希在构建时核对。

附件提供 Windows/Linux 安装包、对应源码、SBOM、SHA256 和验证摘要。
