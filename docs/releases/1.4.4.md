# ConWU 1.4.4

修复更新下载缓慢时被固定超时中止、失败后丢失进度的问题，新增 GitHub／Gitee 双源 MSI 下载弹窗。升级保留已有设置、网络身份、虚拟 IP 与证书。

- 点击“下载更新”或“继续下载”后，弹窗左右分别显示 GitHub 和 Gitee；各自提供“下载 MSI”和“访问 GitHub／Gitee”。网站链接允许自行下载后本地安装。
- 两个内置源均使用同一版本的完整 MSI，下载来源由用户选择。Gitee 固定为 `space4sgsa/ConWU` 官方仓库；不在软件中保存发布令牌。版本、长度和完整 SHA-256 继续依据官方发布信息校验，安装前再次核对 MSI 产品身份。
- 下载仅对连接和无数据停滞设置超时，持续收到数据时允许超过十五分钟。断线会自动重试并刷新 CDN 跳转；重试、关闭面板或正常重启后台后保留同一安装包的进度。支持 Range 的源从断点恢复，源不支持时安全重新下载。
- 修复不支持 Range 的服务器重复拼接文件，以及下载取消时直接显示英文异常的问题。失败后保留进度并显示“继续下载”，校验失败的内容不会进入安装流程。
- 下载完成后仍由用户确认安装，再交给本机独立更新程序，恢复后台和此前启用的网络。本次安装部署保留上一版程序与匹配设置备份。

GitHub 提供完整发行版；Gitee 提供容量限制内的 MSI、Linux 包、源码及校验资料。Windows 完整 ZIP 超过 Gitee 普通附件上限，继续放在 GitHub。移动端和 APK 保持暂停。

验证范围见附件 verification 文件；下载与安装检查不等同于新的公网打洞或高码率串流验收。
