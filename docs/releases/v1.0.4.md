# StreamLink 1.0.4

已有入口现在是一条独立连接方式：只使用填写或订阅得到的入口，失败后给出提示，由用户手动切换到“自选服务器”进行自主打洞。订阅仍会按设置定时更新，协议仍由用户选择。

- 停止已有入口模式的 STUN、自动映射和自主打洞，并通知对端遵循该限制。
- 修复准备中的打洞候选提前接管路由、导致已可达入口也无法完成认证的问题。
- 入口先连通时回收未完成的候选；切换连接方式会确认后重新建立连接，修改入口地址仍可热更新。

两端都请更新，以共同执行新的连接策略。已有网络、设备授权和设置保留；入口本身不可达时仍需修正映射或手动选择自主打洞。此前报告的删除网络超时不包含在本次修复中。

验证记录随候选保存，不以短时回环或一次直连代替正式长期串流与多机完整验收。
