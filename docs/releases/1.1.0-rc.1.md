# ConWU 1.1.0-rc.1

这版把连接流程收敛到 16 位直连码，也补齐了 Windows 和 Linux 的双机多网络功能。经用户确认，将三机当前使用的这批安装包转为正式 Release，并设为最新版。程序构建标识和附件名称沿用 `1.1.0-rc.1`，便于与已安装程序及原始校验记录对应。

- 主机创建网络并生成直连码，从机输入后申请；核对双方校验码、主机批准后，自动获取网络设置。
- 自主打洞默认使用 PKARR 更新和发现地址，不需要注册域名。自己的 HTTPS 协调服务器作为高级选项保留。
- 已有入口继续使用填写的地址或 HTTPS/TXT 订阅，支持按标签区分入口；静态地址变化时需要重新填写。
- 每个网络一主一从、双向通信。同一设备可以创建或加入多个网络，概览统一显示，每网设置独立保存。
- 简化创建、加入、退出和设置界面，修复多网络配置相互覆盖、草稿丢失及慢请求导致的输入状态问题。
- Linux 提供 CLI、WebUI 和可选的域名管理入口，也可以独立提供协调服务。

Windows 下载 `ConWU-1.1.0-rc.1-x64.msi`；Linux x86_64 / glibc 下载 `ConWU-1.1.0-rc.1-linux-x64.tar.gz`，解压后运行 `sudo ./install.sh`。Linux 的 Alpine/musl 和 ARM64 不适用此包。Windows ZIP 供需要完整文件包的用户使用。

请两端一起更新。旧单网络与当前双机网络格式不兼容，需要按提示重新建立；同语义的设备设置继续保留。当前数据通道仍为 FakeTCP＋HTTP，纯 TCP 是预留选项。

冻结源码的 74 组核心回归、真实浏览器与慢 API 检查、隔离 Windows MSI 升级及 Linux 安装生命周期检查通过；三机已完成部署并核对设置。PKARR 公共网关的地址更新与双向确认也已验证。长期公网大码率串流、完整 30 轮可靠性及跨账户矩阵未在本次自动化验证范围内，正式发布不改变这些记录。应用安装包尚未进行发布者签名。
