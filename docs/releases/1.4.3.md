# ConWU 1.4.3

修复自主打洞发布错误 STUN 入口的问题，并将暂时断开与永久退出分开。升级保留现有网络、设置、身份、虚拟 IP 和证书。

- 核验 TCP STUN 将服务端自身公网 IP 当作映射结果返回的异常响应。通过其他已配置的独立服务确认出口，无法确认时丢弃候选并切换服务，避免把错误地址写进直连码或用于复连。覆盖普通映射、维护恢复、TCP 候选池及预测／校准路径；STUN 候选仍不保证公网可达。
- “加入网络”列表提供“断开连接／重新连接”。断开后不转发业务数据，保留必要保活、成员与入口同步，以及原网络身份。重新连接无需配对；重启后台或升级也会保持已保存的断开状态。主机显示对机已断开连接。
- 左侧仍叫“退出网络”。从机确认后删除本机网络和重连凭据，发送本人签名的退出通知；主机验证后清除该从机，原网络保留并等待新设备加入。主机离线时，本机仍可退出，受保护的通知队列会在后台重启后继续投递；收到主机签名回执才视为清除完成。两端均需 1.4.3 支持该通知，旧主机升级前保留待发送状态。
- 创建网络列表仍使用“删除网络”；本机作为主机时，左侧退出操作同样删除该网络并撤销从机授权。其他网络和本机全局设置保留。

本版发布 Windows x64 MSI、Windows 完整包、Linux x64 包、源码、SBOM、校验值及验证说明。Windows 安装版可通过设置中的内置更新下载并确认安装。Android 开发与 APK 更新暂停，本版不含 APK。

验证范围以随包 verification 文件为准。隔离回环测试验证控制保活、暂停业务、同身份恢复和签名退出，不代表真实 NAT 或高码率串流已完成验收。
