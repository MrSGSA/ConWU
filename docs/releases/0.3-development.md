# 0.3 开发与验收记录

本轮需求：加入／创建／设置分层界面；操作中的反馈和互斥；彩白渐变视觉；六位限时配对码；可选服务及托盘；独立协调服务器；TCP/UDP 选择与 STUN 列表；日志配置、GitHub 和更新检查；缩减运行包。

稳定基线为 v0.2.0-preview。保留原生 udp2raw 数据面及原有正在运行的网络，开发验收使用独立配置目录；更新现有服务须通过设置中的显式安装／更新操作。

实现约束：业务始终直连；协调服务器只交换端点与配对消息。短码只定位临时配对会话，不作长期加密密钥；使用临时 ECDH 与加密邀请、创建端批准及双方校验码。公共协调服务器占位不伪装成已可用；UDP 标为实验并说明不能保证绕过 QoS。创建／加入决定虚拟地址槽位，公网入口仍自动选择。

独立部署目标为 https://streamlink.space4sgsa.com/，源站 HTTP 127.0.0.1:42861；原 searxng 路径供旧版兼容，待新链路验证后另行退役。

图像采用内置 GPT-Image 工具生成，项目资源为 src/StreamLink.App/Assets/pearl-background.png。最终提示词见 Assets/image-prompt.txt。

已通过（2026-10-10）：

- 9 项原生回环协议测试：HTTP/普通报文边界、丢包不阻塞后续包、乱序、重放、篡改、错误密钥、畸形包和 UDP 实验模式。
- 35 项既有核心检查：STUN、邀请、质量测试、入口选择、控制协议及进程恢复。
- 36 项短码/设置检查，扩展到真实本地 HTTPS 后累计 41 项：P-256 承诺、校验码、跨房间/候选者重放、密文篡改、owner/guest 权限、过期、撤销、一次性批准、证书指纹错误、缓存禁止、真实 HTTP 限流。
- 23 项 Windows 隔离检查：前台启动/停止、未配对启动拒绝、配置加密与恢复、设置不能修改配对身份、后台实例互斥、安装清单校验与路径穿越拒绝、同目录重装、日志密钥脱敏、即时忙碌提示、重复点击拦截、成功及失败恢复按钮。
- 加入、创建、设置页面在本机 240 DPI 预览；生成素材已嵌入程序集。日常包去除 CLI，并让 GUI/服务共用一套 .NET 运行时。

正式包复用 v0.2 已验证的 udp2raw-native.exe（SHA256 49D597C3EA4F02917DC25FD8A3CA4AC83A12F5BF1422BE893BFCD3186C1BC454），传输源码没有改动。重新编译得到的 PE 可能因时间戳而改变哈希，发布时通过 Package.ps1 的 NativeBinary 参数显式选择稳定二进制。EasyTier core/cli 仍为同一固定版本。包体实测见 Release 的验证摘要。

没有停止两端 0.2 服务、切换配对或改动现有网络做公网吞吐量复测。安装清单复制与前台生命周期已经隔离测试，但未用新版替换正在运行的生产服务；服务迁移、干净系统、冷启动未登录、长期运行及跨机器短码到真实 P2P 的完整回归仍待测试。历史性能数据明确保留为 0.2 记录。
