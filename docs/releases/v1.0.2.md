# StreamLink 1.0.2

这次主要把组网和设置的操作整理清楚了。

- 设置改为全局保存。切换页面后仍会提示未保存的修改，校验失败会保留全部草稿。
- 协调服务器、端口、证书和 STUN 分开设置。已有入口逐行填写，支持 HTTPS/TXT 等订阅，目标主机的协调开关统一放在入口上方。
- 服务器组网使用配对码，无服务器组网使用直连邀请。两种申请都要由主机批准；新邀请不会提前分配成员密钥。
- 设备列表包含本机，连接方式和流量更容易查看；操作说明默认收起。

下载 `StreamLink-1.0.2-x64.msi`，结束串流后更新两端。现有网络和设置保留。新版无服务器邀请以 `SL6.` 开头，两端都需更新；旧 `SL5.` 邀请请由主机重新生成。

默认仍为 FakeTCP＋HTTP，连接协议由用户选择，不自动回退 UDP。协调服务器不转发串流业务。

本次验证覆盖实际本地 WebUI、受限控制接口、设置与邀请审批，以及隔离实例和原生本地链路。没有把这些结果当作公网串流测试；八台 Windows、长时间压力和跨账户场景仍未全部覆盖。应用尚未进行发布者签名，官方驱动沿用上游签名与固定哈希。

MSI、便携包、协调服务、源码、SBOM、验证记录和 SHA256 随本次附件提供。上一版继续保留，方便回退。
