# StreamLink 1.0.3

这版先处理反复组网和后台反馈中的问题。

- 同一设备退出后重新申请，由主机批准替换旧成员授权，保留原虚拟 IP；其他设备不受影响。
- 操作响应丢失时继续查询原来的操作，减少误报后重复点击；审批重试沿用已经签发的授权。
- 协调服务的连接、证书、响应超时与主机入口未响应分别说明。创建配对码失败时不留下半创建的网络。
- 后台恢复后清除状态超时提示，临时操作提示定时消失。
- 修复重复运行同版本安装包时，后台未重新启动导致的安装就绪检查失败。
- 同意在左、绿色，拒绝在右、红色；确认同意的弹窗也使用绿色。
- 侧栏将设备总数和“与其余 n 台设备直连”分行显示。
- 内部 STUN 源端口不可用时重新分配，固定接收端口保持不变；改进 Wintun 残留接口的检查和恢复。Windows 仍缓存旧网卡时，重开会显示最多 30 秒的设备配置等待，支持取消。

下载 `StreamLink-1.0.3-x64.msi`，结束串流后更新两端。服务器组网也请更新随包的协调服务，以支持重新加入的身份关联。已有网络和设置保留，无需重新创建网络。

旧版已经留下的重复成员缺少可靠的身份关联，需由主机从概况中移出多余的离线记录。软件不会因为名称相同就删除另一台设备。重新加入仍需主机核对校验码并批准。

默认仍为 FakeTCP＋HTTP，用户自行选择协议，不自动回退 UDP。业务保持设备之间直传。真实 TLS、QUIC 等新方法先做独立实机实验，不包含在这一版中。

检查记录随附件提供。本地、隔离实例和原生链路验证不等于长时间公网串流验收；八台 Windows、跨账户和完整长期矩阵仍未全部覆盖。应用尚未进行发布者签名，官方驱动继续按上游签名与固定哈希核验。

安装包、便携包、协调服务、源码、SBOM、验证记录和 SHA256 一并提供，1.0.2 继续保留作为回退版本。
