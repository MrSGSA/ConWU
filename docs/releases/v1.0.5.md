# StreamLink 1.0.5

这次主要解决设置丢失、界面短暂失去响应和需要手动刷新的问题。

- 设置不再随退出、删除、创建或重新加入网络而清空；升级继承原有设置。
- 慢速停止和资源回收不再堵住本机状态读取，界面区分网络正在停止、后台暂未响应与授权过期。
- 修复退出后配对码输入异常、后台轮询锁住设置输入区、下拉选项被刷新打断等问题。
- 保留未保存草稿和恢复历史；多个窗口保存发生冲突时保留草稿，面板会话变化可安全恢复。
- 补齐已有入口的实际连接信息，增加天、时、分、秒的已直连时间。

已有入口仍只走已有入口，协议仍由用户选择。验证范围和实机结果随候选记录；长期大码率串流与完整多机发布门槛单独验收。
