StreamLink 0.3.0 将配对和日常连接集中到“加入网络／创建网络／设置”三页。输入 6 位短码后点击加入，双方核对校验码，由创建端批准；主页面展示两台设备、虚拟 IP 和实际连接状态。耗时操作立即显示进度、禁用冲突按钮，完成或失败后恢复。

- 彩白渐变背景使用 GPT-Image 生成，日志移至独立窗口；新增日志等级/目录、设备名、GitHub 和更新检查。
- 后台服务改为设置中显式安装、更新、卸载；无服务可前台运行，托盘图标和关窗常驻可选。
- 新增独立协调服务与自填服务器，公共服务器保留占位；源站可用同机 Cloudflare Tunnel 接入。业务始终 P2P，无业务中继。
- TCP/FakeTCP 为默认，UDP 映射标为实验；新增社区 TCP STUN 快照和列表补充。原生传输内核与固定 EasyTier 版本保持不变。
- 界面和服务共用一套 .NET 运行时，运行包去除开发用 CLI；完整 ZIP 从 128.89 MiB 减至 70.71 MiB，减少约 45.1%，仍无需预装运行时。

验证包括既有核心回归、短码的公钥承诺/权限/过期/重放、真实本地 HTTPS 配对及限流、隔离前台生命周期、配置加密、安装文件校验、界面忙碌和错误恢复。具体计数及包体大小见附件 verification-0.3.0.json。没有中断现有 0.2 网络进行公网吞吐量重测；历史 50 Mbps 零丢包记录不代表本版已重新完成相同测试。

升级前保留旧包并备份受保护的 profile.dpapi，关闭旧界面后运行新包。已有 FakeTCP 配对可继续用原服务；在设置点击“更新后台服务”才会切换。若迁移协调服务器，两端填同一新 HTTPS 地址后重新配对。Cloudflare 源站应填 `http://127.0.0.1:42861`，路径留空；它与客户端填写的公网 HTTPS 地址不同。

这是双端、自托管预览版：不支持多人 Mesh，不保证所有 NAT/运营商 QoS 环境；纯 UDP 未获得与 FakeTCP 相同的绕过证据。公共协调平台、自动升级、干净系统及长期运行验收尚未完成。短码协议仍需独立安全审计，务必核对双端校验码。应用尚未签名，私有仓库下载需要 GitHub 访问权限。
