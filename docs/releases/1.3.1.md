# ConWU 1.3.1

修复已有入口网络仍尝试首次配对旧地址的问题。取得主机配置后，后续连接只使用当前保存的入口来源，避免主机重启、映射端口变化后继续尝试过时地址。

- 当前 TXT、HTTPS 或手动入口取代该对端的旧引导地址和旧入网来源；订阅暂时解析失败时继续刷新当前来源，不回退首次配对地址。
- 启动时按当前配置整理旧版留下的运行缓存，保留设置、网络身份、虚拟 IP、证书和配对关系，无需删除网络或重新配对。
- 没有其他入口配置的手动直连保留必需的引导地址；本机入口与对端入口、不同网络的来源继续独立处理。已认证 PKARR 绑定同样取代对应的历史引导入口。

回归覆盖完整审批和配置继承、TXT/HTTPS/静态入口替换、连续重启、订阅端口变化后的加密报文恢复、设置保留，以及双向 PKARR 重启恢复。随附 verification.json 记录构建、三机升级和设置继承的验证范围；合成回环测试不等同于实际串流验收。

Windows x64 推荐 MSI；Windows ZIP、Linux x86_64/glibc tar.gz、对应源码、许可证、SBOM 和 SHA256 同时提供。Windows 安装器内部版本为 **1.3.2**，保证从 1.3.0 的安装器正常升级。

现有网络继续使用已选协议，沿用上一版的打洞、映射和实验协议能力。更新不增加业务中继或自动 UDP 回退。应用程序仍未进行发布者签名，官方驱动的签名和固定哈希在构建时检查。
