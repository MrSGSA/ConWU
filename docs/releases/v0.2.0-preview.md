# StreamLink v0.2.0-preview

面向 Windows x64 的双端 P2P 虚拟组网预览版。通过原生 udp2raw FakeTCP + 明文 HTTP 特征传输，尝试改善特定网络下 UDP 业务的 QoS 限制，业务数据始终直连。

## 下载与启动

下载 `StreamLink-0.2.0-win-x64-preview.zip`，两端分别解压，以管理员权限运行 `StreamLink.exe`。一端创建网络并复制邀请，另一端粘贴邀请加入。连接后使用界面显示的虚拟 IP。

无需预装 Lucky、EasyTier、WSL、Python 或 .NET。关闭窗口后后台服务继续运行，点击“停止网络”才会断开。完整操作、网络条件和回退方法见包内 `使用说明.md`。

## 本版内容

- 原生 Windows udp2raw 客户端和服务端；TCP STUN 保活、UPnP 短租约映射与自动端点更新。
- 自动选择可提供入口的一端，记忆实际成功方向；可编辑 TCP/UDP STUN 列表。
- 持久配对、Windows 自动启动服务、断线恢复；固定虚拟 IP `10.129.129.1` / `10.129.129.2`。
- 内置 EasyTier 2.6.4、WinDivert 2.2.2、Wintun 0.14.1 和 .NET 10.0.12；提供第三方许可证及对应源码。
- HTTPS 发现服务只交换加密端点公告，不提供业务中继；发现服务源码可自行部署。

## 验证结果

- 最终候选版本 Akane → Thinkbook：50 Mbps、20 秒，接收 104152/104152 包，49.99296 Mbps，零丢包。最终状态采样 RTT 约 15.4 ms，不代表全程延迟统计。
- 35 项核心校验、12 项真实服务检查、5 项公网发现检查通过；原生传输二进制未变，沿用此前 9 项传输回归结果。
- 发现服务停机期间 P2P ping 20/20 成功；验证了服务崩溃自动恢复、映射端点变化后的自动重连和两端发布文件一致性。
- 本次发布整理了文档及附件，运行程序保持上述已验证二进制。完整记录见包内 `实测报告.md` 和 `验证摘要.json`，独立摘要附件为 `verification-0.2.0.json`。

## 已知边界

- 当前稳定路径是 FakeTCP + HTTP 特征，**不是 HTTPS/TLS 业务伪装**；纯 UDP 实验仍受约 6 Mbps 限制。不能保证所有网络均可绕过 QoS。
- 通常至少一端需要可用的路由器 UPnP 转发及可被另一端访问的上游 TCP 映射；不保证双严格 NAT 直连，不提供业务中继兜底。
- 仅支持一对设备和固定网段；部分网卡初始化或重连需要约 30–55 秒。
- 真实整机冷启动未登录、全新 Windows 驱动首次安装、长期高负载及休眠换网尚未完成验收；应用 EXE 尚未签名。
- 内置发现服务为本次预览环境配置，可改为自托管服务，不承诺公共服务可用性。

`SHA256SUMS.txt` 列出两个压缩包及独立验证摘要的 SHA-256。下载后可使用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 校验。
