# StreamLink 1.0.1

这一版终于可以先放下折腾，用它好好串流了。

1.0.1 延续 rc.14 的功能，整理了安装包和使用说明。主要改进来自这段时间的双机使用：连接进度更清楚，修改入口不再重建健康连接，更新安装时的旧进程和 Wintun 处理也做了修复。

- 默认 FakeTCP＋HTTP，连接协议由用户决定，不自动回退 UDP。
- 全部操作收进 WebUI，托盘保留打开面板和退出。
- 支持已有公网入口、Lucky 等打洞结果，以及自动更新的 HTTPS 订阅。
- TXT 与 HTTPS 支持 `streamlink=` 标签，多种入口放在一起也能分别读取。
- 支持六位配对码与无服务器直连邀请，加入页自动识别。

**安装**：下载 `StreamLink-1.0.1-x64.msi`，结束串流后更新两端。已有网络和设置保留。ZIP 为备用运行包，协调服务包供自建服务器使用。

作者的两台 Windows 设备已验证通过 Lucky 入口建立直连，本轮使用反馈良好。入口、连接恢复、控制接口、WebUI 与服务端回归已完成；此版业务源码与 rc.14 一致。

八台 Windows 同时运行、跨账户和长期压力测试尚未全部覆盖。应用未做发布者代码签名，随包官方驱动保留原有签名。不同网络的可达性与效果仍需要实际确认。
