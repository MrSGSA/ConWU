# 0.5.4 开发预发行

保留已经有效的原生 Wintun/MeshLink/udp2raw FakeTCP＋HTTP 默认组网与禁止业务中继。本版新增独立默认关闭的备用保留、认证送达反馈、有界负载诊断和实验共同质量选路。

自动选路需双方和协调服务支持、双方目标一致、显式备用/诊断许可及出口额度。路径质量接近时保留原路径；普通切换需持续收益、双端批准、共同提名、驻留和冷却。原生进程退出可使用仍新鲜且合格的备用路径恢复。诊断或资源证据不足则保持原策略，不用低空载 RTT 判断串流容量。

完整细节与各项边界见 [M6记录](../m6-quality-selection-20261013.md) 和 [总执行状态](../execution-status-20261011.md)。本地正式收发夹具不等于公网严格 NAT 或八真实终端；完整 M0—M9 发布 Gate 为 NotPassed。安装包、真实安装和回滚结果另行记录，本说明本身不表示已经发布或安装。

默认仍 prefer-faketcp，原有实验能力、pacing、诊断、备用和自动选路均需显式开启。旧客户端/后台/协调服务缺少独立能力时保持兼容行为。

回退时停止候选网络、等待资源退出，然后从保留的旧完整包及配置备份恢复；保留旧目录，不删除共享驱动或无关配置，不恢复旧成员授权目录。现用服务不会由打包操作替换。
