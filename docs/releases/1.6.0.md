# ConWU 1.6.0

这次更新把重点放在两件日常的小事上。两台设备在复杂网络里更容易连上，暂时离线后也能自动找回原来的连接。Windows 用户还可以直接在 ConWU 里串流、操作对方桌面和互传文件。

## 异地直连更稳

- **分享 16 位码，核对校验码后批准。** 新建网络默认使用协调服务器。两端会同步探测计划，自动选择候选、安排握手。协调服务器负责交换建连信息，串流和文件数据由两台设备直接传输。
- **连不上会自动再试。** FakeTCP、Phantun、Mimic、TCPRAW、TCP 和 HTTPS 都支持协调首配与成员重连。遇到端口映射变化或单轮超时，程序会按当前协议重新探测，必要时换端口和接收器。对端重新上线发布新状态时，可以提前唤醒重连。
- **断开后可以接着用。** 普通断开保留网络身份与必要保活，重新连接无需配对。设备离线再上线后，后台会尝试恢复原网络。

三机实网复测使用两个 Windows 端和一台 Linux 协调器。六种协议各测五组，首配直连、普通断开恢复和冷停恢复分别通过 **30/30**，合计 **90/90**。冷停通过停用测试网络、释放运行实例后再启动同一网络来模拟设备离线。

## Windows 串流和文件互传

- **一扇窗口就能用。** 点击 ConWU 左上角的标志切换到 Projection，在左侧选已配对设备，点封面上的「串流」即可播放。内置 Sunshine 和 Moonlight，复用 ConWU 的配对与设备权限。小窗按画面比例适配，也可用快捷键全屏和释放键鼠。
- **常用画质设置放在手边。** 分辨率可跟随本机、跟随对端或自定义。设置帧率后，码率提供保帧优先、自动估算和画质优先三档，并显示所需带宽。串流中可打开性能统计查看帧率、延迟和当前组网协议。
- **文件可双向传。** 授权后可以在双栏界面打开本机和对端目录，勾选文件传输，也可以拖到另一栏的目标目录。串流时可开启文本剪贴板同步。
- 准备串流时保留设备封面，结束时显示最后一帧。切窗和结束串流会释放键鼠捕获，回到面板后可以继续操作设置和文件互传。

## 日常操作

加入申请的状态和取消按钮放在「请求加入」下方。概况更新流量图时保留滚动位置。「退出网络」直接列出本机创建和加入的网络。Windows 托盘右键菜单也可以退出 ConWU 面板。

## 安装与升级

- **Windows x64** 下载 `ConWU-1.6.0-x64.msi`。已有安装可以直接升级，保留现有网络身份和设置。安装后从系统托盘打开 ConWU。
- **Linux x86_64** 下载 `ConWU-1.6.0-linux-x64.tar.gz`，解压后运行 `sudo ./install.sh`。Linux 可用作组网端点或协调服务器。[Linux 安装说明](https://github.com/MrSGSA/ConWU/blob/v1.6.0/packaging/linux/README.md)
- 使用自建协调服务器时，建议将组网两端和协调服务器一起升级到 1.6.0。[协调服务与升级](https://github.com/MrSGSA/ConWU/blob/v1.6.0/docs/协调服务与升级.md)
