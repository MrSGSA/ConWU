# ConWU 1.4.2

本版正式提供 Windows 的 UU 远程串流接管与本机独立更新，保留已有网络、设置、身份和证书。Windows、Linux 公共核心同步更新；Android APK 保持原测试版本，另行优化。

- 左侧新增“UU远程”，默认关闭。开启后自动使用所有已直连的 ConWU 网络，随 UU 目标设备变化切换，两端可同时开启。左侧只保留检测状态，右侧按网络显示状态和收发流量；低流量、空闲与持续传输分别展示。既有 UU 会话需要重新连接。
- 接管仅识别经过安装路径与进程身份核对的 UU 程序，不修改其登录、授权或媒体加密。网络离线、关闭接管或服务退出时撤下临时规则；一条网络离线不影响其他健康网络。Windows 已验证真实 UU 桌面会话经过 ConWU，UU 的终端、文件浏览等附加功能不属于本次保证范围。
- Windows MSI 安装版先完整下载并校验官方更新包，用户确认后由本机独立原生程序执行 MSI。更新不依赖远程连接或原后台继续运行；安装后恢复后台、原先启用的网络和普通用户托盘，对端离线时等待重连。修复升级中的服务重建、安装登记和开机启动恢复。
- 项目、程序集与程序文件统一采用 ConWU 命名。旧服务名、安装目录、数据目录、加密标签及线上协议标识继续兼容，升级不要求重建网络。
- Linux 同步公共核心、WebUI 与命名兼容改进，保留 CLI、协调能力和既有设置；不提供 Windows 专用的 UU 进程接管，更新仍由用户部署。

发布附件包含 Windows x64 MSI、Windows 完整包、Linux x64 包、源码、SBOM、校验值和验证说明，不包含 APK。安装与验证范围以随包 verification 文件为准；检测到 UU 流量不等同于完整交付、画质或高码率性能保证。
