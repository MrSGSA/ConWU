# StreamLink 0.5.0-preview 开发候选

本包用于下一版独立验证，**不是 M0—M9 全部验收完成的正式推广版**。仍以现有 udp2raw FakeTCP+HTTP、原生 Wintun 和自主 MeshLink 组网为基础，最多八成员，业务只走直接连接。

## 默认行为

- 保留兼容 TCP 入口和 FakeTCP 优先。可以使用已有手工 Lucky 地址或自动显式映射入口。
- 原生双主动、UDP 降级、TCP SYN 诊断、独立校准与预测、PCP/NAT-PMP、外层 IPv6 和出口 pacing 均需显式启用，不因安装升级自动开启。
- 兼容 TCP helper 与原生端口预约使用独占所有权；新增首个业务包、稳定业务区间和空闲路径的恢复诊断。诊断不会将连通直接判为负载质量达标。
- 兼容组网握手与维护报文共用全机限额，各成员错开发送，避免批量重连耗尽突发额度；服务诊断区分准入和预算延后，尚不作为完整物理出口统计。
- 不含 EasyTier、WSL 或 Python；自带 Windows x64 .NET 运行时及 WinDivert/Wintun 依赖。首次联网涉及驱动/防火墙权限，后台服务由用户在设置中安装或卸载。
- 没有服务器或成员业务中继；严格 NAT 未找到直连时明确显示未连通/部分连通。

## 已接入的实验能力

1. 持续持有 TCP helper 源端点，一个源端点一个捕获 broker；授权 native attachment 不再次 bind。
2. FakeTCP 双主动及共同提名，保持 HTTP/bare 序号和不可靠数据报语义。
3. UDP_DIRECT 从 STUN、检查到 MeshLink 保持同一获胜 socket；独立许可和降级提示，健康 FakeTCP 不被抢占。
4. 有界机会窗、后台重试、UDP 降级后的 FakeTCP 恢复及成员路径生命周期。
5. TCP 同源 SYN 观察器接口（需要协调服务器另行配置）；SYN 观察不等于完整握手或业务验证。
6. PCP/NAT-PMP TCP/UDP 后备可独立于 STUN 成功收集入口；支持有界网关通知、IPv4 组播及可让位的控制接收配额。原生 IPv6 UDP 及 broker-only IPv6 FakeTCP，能力不足时保持 IPv4。
7. 可选受管链路总出口 pacing、字节公平队列和诊断统计。当前不覆盖兼容入口进程，性能 Gate 未通过，默认保持 0。
8. 受管原生 SYN/HTTP/bare/心跳在实际注入前按全机预算计账；提名后的业务保持数据报语义。兼容进程和内核 helper 的完整线上账本仍待完成。
9. TCP 750ms 最终观察窗、独立校准与条件预测；包含留出、背景干扰、单调时钟和连续失败门槛。签名预约协商及最多八端口的原生尝试已接入正式 Runner，须双方和服务具备能力及有效校准资格，仍默认关闭。受控模型和回环通过不等于公网预测已成功。
10. 协调 watch 被拒绝后，通过下一预算内的签名成员目录读取核实撤销；已有健康路径不因短期协调不可达立即重建。

## 尚不能承诺的能力

概率增强尚未完成，AutoQuality 不开放；兼容路径与内核辅助流的完整控制账本、兼容与多出口队列仍待补齐。真实公网 SO/UDP/预测正例、完整原生 I/O/PMTU Gate、八台真实 Windows、60 分钟质量、真实网络六分钟协调中断、无人登录冷启动和正式包升级恢复仍需补齐。已有六分钟中断受控集成和公网短窗 SYN 观察，均不替代这些验收。

当前逐项状态见包内 `开发验收状态.md`；源码中完整证据索引为 `docs/execution-status-20261011.md`。失败和待测项不会被打包流程改成通过。SYN-only 观察、LAN 功能、WAN 可用与 QoS 效果分开标记。

## 使用与回退

解压完整目录，运行 `StreamLink.exe`。不要将候选 exe 单独覆盖到旧版本目录。首次仅查看界面和配置不会替换已安装后台；设置中的安装/升级服务才会执行部署并重连。

启用实验设置前保留旧完整包与配置备份。撤回单项实验时，取消对应选项并保存；pacing 填 0。整包回退时先停止网络，等待本版本 native/capture/socket 清理，再从旧完整包安装后台。新包按独立版本/清单哈希目录安装，旧目录保留；安装失败会尝试恢复原服务路径。不要手工终止其他软件、删除共享驱动或全局清理路由。

配置 Version=2 与 MeshLink 协议 4 保持不变，新能力依赖单独 capability。旧版本忽略新增配置时不能继续保持新 live attachment；回退应先退出候选版本。不要回退成员目录授权到旧 revision 来恢复已撤销成员。

此候选包尚未替换现用软件，且不代表协调服务器已部署新能力。生产 EXE 未做代码签名；官方驱动/依赖检查与文件 SHA-256 校验用于来源和完整性核对，包内自列哈希不能代替可信发布渠道。
