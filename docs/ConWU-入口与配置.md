# ConWU：入口、配对和网络设置

每个网络连接一台主机和一台从机，通道可以双向使用。一台设备可以同时创建、加入多个网络；概况合并显示，不在不同网络之间转发业务。

## 创建和加入

主机在“创建网络”填写名称，通过“网络设置”浮窗设置协议、入口、协调与虚拟 IP，然后创建网络、生成配对信息。右侧列出本机创建的网络，可查看配对信息、修改设置或删除。

从机在“加入网络”输入主机配对码，或粘贴主机生成的完整直连邀请。主机在独立的“加入申请”页面核对设备、虚拟 IP 和双方校验码，再同意或拒绝。

批准后，从机通过加密配对通道自动获取该网络的设置。主机的“本机入口”转换为从机的“目标主机入口”，虚拟 IP 单独分配，本机监听与源端口按本机资源处理。本机名称、启动、日志、协调监听角色和管理凭据不会照抄主机。从机可查看这份设置，不能直接编辑或改用本机连接配置。

主机和需要进行自主配对的协调设备应先更新至本候选。旧设备未下发所需设置时会明确报错，不假称已经自动配置。

## 何时需要指定主机入口

能够通过已配置的协调服务器找到主机，或使用包含入口的直连邀请时，无需另外填写入口。

没有可用的协调服务器、仍要使用短配对码时，在“找不到主机？指定主机入口”中填写主机可达地址或订阅链接。短码本身不包含完整地址。

已有入口主机既可以生成短码，也可以生成完整直连邀请。原始地址不包含协议信息；非默认协议初次直连宜使用包含明确协议的完整邀请。软件不通过业务协议回退猜测连接。

## 已保存的设置

网络设置浮窗中的“已保存的网络设置”允许选择已有设置、创建独立设置或另存副本。共用设置保存后更新所有关联网络，生效前显示影响范围。虚拟 IP 属于单条网络，不随共用配置静默修改。

加入的新网络使用主机提供的设置，不引用本机配置库。旧网络的共享引用保留，界面不会为了简化显示就自动拆散引用。退出、删除网络保留本机设备设置和配置库；未使用的设置可在浮窗内删除。

“设置”只管理启动与服务、本机设备名和日志。“协调服务器”是独立页面：使用其他协调服务器和本机提供协调可以同时开启。默认发现地址只用于新连接，不替换已有网络的协调身份；各网络仍可保留自己的必要协调信息。

## 连接策略

**自主打洞**：有协调服务时，通过同一个 HTTPS 协调地址和短码完成申请、候选交换与打洞同步。无协调时可生成直连邀请，但取得 STUN 候选不等于入站一定可达；严格 NAT 是否能通取决于实际网络。

**只使用已有入口**：填写主机公网 IP:端口、路由器转发、第三方打通的地址，或 HTTPS/TXT 订阅。主机入口须实际通向 ConWU 接收端口，默认 44680；不是 Lucky 等工具的管理网页。此策略不同时启动自主打洞。

可开启备用协调：已有入口优先，失败后向同一个协调地址查询主机发布的签名候选，不转发串流、不自动改走 UDP。从机通过默认协调查找短码时，也支持查找这类已有入口公告，随后仍直接联系主机并等待批准。

多主机共用来源时，用标签区分，例如内容为 `streamlink1=203.0.113.1:8436`、`streamlink2=203.0.113.2:9123`，分别填写 `txt://entry.example.com#streamlink1` 或 `https://entry.example.com/current#streamlink2`。标签用于筛选地址，不能代替身份认证。

## PKARR 入口发现（实验）

在主机网络设置的“PKARR 发现”中按需开启。它不需要注册域名，通过 PKARR 的 HTTPS 网关向 Mainline DHT 发布签名 DNS 记录。默认关闭。

每条网络保留自己的发布密钥，网络重启后更新同一个 `pkarr://公钥` 地址。已有入口会先解析为当前地址；自主打洞则只能发布已经准备好的候选，PKARR 本身不负责穿透。入口来源变化或查询到新地址后更新公告，内容未变时定期重发。界面显示发布状态、当前公告地址和最近成功时间。

直连邀请与批准后的设置会携带这条发现线索，从机保存后可重新查询主机的新入口。公网地址属于公开公告；网络私钥、入网凭据和管理密码不会发布。查询结果还须通过 ConWU 网络身份认证，查到地址不代表已直连。

实验版使用上游默认 HTTPS 网关，不提供原生 UDP DHT 客户端。公告有时效，签名校验、当前进程内的旧版本检查与主机持久序列号已经实现；跨网公网发布的稳定性仍需实际环境验证。不把它作为必须依赖的唯一发现路径。

## 重启、退出和回退

成功加入后会持久保存入口来源和网络身份。固定入口不变时继续使用；订阅与 PKARR 会重新查询地址；协调网络重新交换候选。只保存一次性裸 IP:端口且地址已改变时，仍需更新入口。邀请的申请有效期结束，不会使已批准成员的网络授权同时失效。

从机删除网络只移除本机记录，不删除主机网络。远端清理未确认时可选择只从本机移除，界面不会把远端撤销标成成功。

更新保留原有同语义设置及旧程序回退。当前候选的回归范围见随包记录，实际公网 Moonlight 串流由使用者验证。
