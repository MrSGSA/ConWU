# M7：受管原生 IPv6 FakeTCP 接入

从 `6fc6444` 继续。新增外层原生 IPv6 FakeTCP+HTTP 的正式候选收集、能力协商和 Runner 接线；内层仍为 IPv4。它是默认关闭的实验功能，本次未证明物理 WinDivert、公网 IPv6、防火墙或 PMTU Gate。

## 实现与兼容

- `TcpEndpointLease` 持续持有 IPv6 TCP helper，独占且 V6ONLY。原生仍按授权发送，不第二次 bind。捕获所有者、attachment、Active 引用沿用既有生命周期。
- ABI 1 的 IPv4 96B 描述符保持不变。IPv6 使用 ABI 2/144B，追加三个完整 16B 地址，明确要求 broker。身份、代次、角色、请求序号和整段描述符绑定；控制管道和 raw 管道必须使用同一描述符。
- C# WinDivert 过滤器使用 IPv6 字段，准确排除 helper 双向 tuple；IPv6 不读取 IPv4 校验和位。Raw 注入设置 IPv6 标志并计算 TCP 伪首部校验和。C++ 复用既有 IPv6 序列化，不修改 HTTP/bare 重叠序号、seq-mode 3 或业务数据报语义。
- 解析仅支持固定 IPv6 头加 TCP；扩展头、分片和 jumbo 布局拒绝。旧四字节地址槽在 ABI 2 中须为零。生产拒绝 loopback、mapped、compatible、scope、link-local 等不适用地址；只有协议测试构建允许回环。
- `--native-info` 声明 `ipv6=true, ipv6Abi=2, ipv6Attach=broker-only`。独立非受管 IPv6 与 native raw UDP IPv6 未支持。端点观察服务仍仅支持 IPv4，IPv6 helper 不向它发送诊断探测。
- 新配置 `FakeTcpIpv6=false`。服务、双方成员、原生组件能力齐全且本机具备合规物理 IPv6 地址时，第一轮可使用 IPv6，第二轮保留 IPv4 回退。收集和机会窗沿用现有限额，不为换地址族延长总期限。没有合规源地址时给出明确原因并继续 IPv4。
- UDP IPv6 能力不能授权 FakeTCP IPv6。仅 FakeTCP 策略不会因 IPv6 失败而改用 UDP；健康 FakeTCP 不被抢占。旧组件缺少能力时继续 IPv4。混合版本测试为能力缺失模拟，未运行旧发布二进制。

原生 `native-so-state` 的 CTest 通过。应用、服务、协调服务及相关测试 Release 构建通过。界面截图 `m7-ipv6-native-settings-20261011.png` 检查了默认关闭和条件禁用。

上述 raw 收发使用内存适配器，Wintun 使用内存 IP 适配器。独立校验器核对 IPv6 TCP 伪首部校验和与包长；WinDivert 官方 DLL 仅编译/求值过滤器，不打开驱动。不能据此声称线上无内核 RST、真实 helper 不被截流或无分片。

四组 Runner 首次双方 Connected 分别为 8.695s、16.128s、7.434s、7.413s，包含启动与协调，各一次，不是公网建链统计。完整内层 1280B 对应实测序列化 IPv6 FakeTCP 外层 **1466B IP 包**（同 profile IPv4 为 1446B），不能套用 UDP 的 1392B。实际路径 MTU 仍需抓包和不分片验证。

第一次 smoke 因 `native_server.cpp` 遗留 IPv4 限制失败，保留在 `m7-ipv6-native-smoke-20261011.*`；修复后 smoke2 和 30 轮通过。不是将失败测试删除后宣称全通过。哈希和构建来源见 `m7-ipv6-native-manifest-20261011.json`。

## 未完成 Gate 与回滚

尚缺真实 IPv6 物理 WinDivert/Wintun、双 Windows、公网源端点和状态防火墙、线上 RST、PMTU、长时间和八终端证据。本机最近只读检查无可用原生全局 IPv6，本轮没有修改地址、MTU、路由、防火墙或线上安装。

关闭“FakeTCP IPv6”并保存即可回到 IPv4 候选；ABI 1 与 UDP IPv6 行为保留。源码基线为 `6fc6444`。二进制回退须先停止候选进程并等待其 attachment/capture 清理，再启动基线；不跨版本共享 live attachment。新增配置缺省关闭，无数据库迁移。PCP/NAT-PMP 主动通知及其他 M7 Gate 继续待办。

参考：[WinDivert 官方文档](https://reqrypt.org/windivert-doc.html)（IPv6 过滤、标志与校验和）；本地 `windivert.h` 核对 IPv6/IPChecksum/TCPChecksum 位。协议依然使用 `udp2raw-http-c4995ea`。
