StreamLink 0.4.0 原生多机预览版

本版范围
默认运行包不再携带 EasyTier core/cli 或 EasyTier 源码。使用官方签名的
Wintun 0.14.1 驱动，由 StreamLink 自己管理 IPv4 虚拟网卡、成员认证、
数据报封装、心跳和成员间直连；公网传输仍使用原生 udp2raw FakeTCP +
明文 HTTP 特征。HTTP 特征不是 HTTPS，也不是绕过所有网络 QoS 的保证。

每个网络最多同时 8 台设备，一台机器当前加入一个网络。创建者逐台生成
6 位短码，核对双方校验码后批准加入。创建者可以移除成员，无需重新创建
整个网络。每名成员获得独立凭据和固定 IPv4 地址；移除后不复用旧槽位。
网段从网络身份分配为 10.160–223.x.0/24，启动时检查本机地址冲突。
一台机器只创建一张虚拟网卡；单个对端地址变化不会重建其他链路或网卡。
创建者只负责成员授权，并不是业务服务器；其他成员已有的直连不依赖它转发。
如果批准请求超时，可等待状态确认或重试。此时换码不会自动撤销已经签发的
成员，以免误断已加入设备；未完成的成员可以在列表中手动移除后重新邀请。

直连边界
这是 IPv4 三层单播网络。没有业务中继、成员间转发、默认路由或 DNS 接管。
不能打通的设备对显示未连接；A-B 和 A-C 可连不等于 B-C 一定可连。
广播、多播、IPv6、跨网段路由不在本版实现范围。
默认仍为 TCP STUN + UPnP / 已有手工映射 + udp2raw FakeTCP；可选择 UDP
实验模式。Windows 防火墙只放行已授权成员的虚拟 IP，成员数据还需独立
链路认证和源/目标地址校验。虚拟接口自身不启用 IP 转发。

界面
加入/创建/设置继续分开。设备列表显示各自 IP、直连状态和 RTT，支持复制
IP、选择测速设备，以及创建者移除单成员。邀请下一台设备不停止已有连接。
按钮悬停、按下及导航颜色有 160 ms 局部过渡，完成后停止计时器；隐藏窗口、
系统关闭客户端动画或高对比度时停用动画。设置中可关闭界面动效。
滚动背景继续使用缓存，不逐帧缩放背景图。

从 0.3.x 升级
0.3.x 是旧双机组网协议，与 0.4 原生多机网络的数据格式不同，需要双方升级
后重新创建/加入网络。不要只升级一端后期待旧配对立即连接。
现有旧配对不会自动删除。轻量包读取到旧配对时显示“旧网络需要迁移”，
不自动安装 EasyTier 或悄悄更换身份。后台服务仍需在设置中由用户更新。
当前开发验证没有更新两台机器正在使用的 0.3.2 后台。
当用户明确创建/加入新版网络来替换旧配对时，自动备份旧配置到受限目录：
%ProgramData%\StreamLink\profile-before-native-<时间>-<标识>.dpapi。
回退时先停止新版并退出前台；如安装过新版后台，先在设置中卸载。使用旧版
完整包，把同机生成的备份复制为 profile.dpapi，再按需安装旧版后台并启动。
备份使用 Windows DPAPI，不可拿到另一台机器直接恢复；文件包含加密凭据。

协调服务必须升级
新客户端需要 /v3/mesh/... API。新服务继续兼容原 /v1 公告和 /v2 短码，
并增加签名成员目录与加密端点公告，不新增业务转发接口。
本轮用户要求先完成本地开发，因此现有公网协调服务尚未切换。
新服务发布物：out/discovery-0.4-linux/StreamLink.Discovery。
部署和回退应按同目录的协调服务运维说明执行；Cloudflare 的域名和 HTTP
127.0.0.1:42861 回源地址无需更改。升级前备份 systemd 单元及数据目录，
保留原可执行文件。/health 应新增 meshProtocol:4 和 maxMembers:8。

本地验证（不是公网测速）
已通过独立成员凭据、签名目录、撤销、乱序立即交付、防重放、旧会话拒绝、
源地址伪造拒绝、禁止转发、MTU 边界、三节点独立路由及退出清理测试。
真实 Wintun 测试覆盖：创建与配置 IP、Windows UDP 应用发送 1200 字节负载、
经原生网卡/加密路由到模拟对端，再注入回真实 Windows UDP socket，最后
退出并确认虚拟 IP 已移除。它没有使用远端 Windows 或公网。
udp2raw 三节点测试使用真实 C++ FakeTCP + HTTP 协议代码和多客户端复用，
仅原始包收发用回环代替；它没有测量 WinDivert 公网路径或运营商 QoS。
已通过独立 HTTPS 服务的三成员目录、加密公告和撤销接口联调，以及旧配对、
服务生命周期、连接调度和高 DPI 滚动回归。

凭据与协议
管理员用 P-256 签名成员证书及单调版本的目录；通过已核对的短码密钥交换
加密交付单设备凭据，不交付管理员私钥。管理员签发时能接触该凭据，是
网络信任根。各成员使用独立 ECDH 链路密钥、HKDF 派生及 AES-GCM 数据报。
会话随机标识与包序号防止 nonce 重用，4096 包窗口允许乱序并拒绝重放；
数据包没有可靠重传或按序等待。本版长期 ECDH 身份不提供前向保密。
协调服务可拒绝服务；离线设备需获得新目录后才知道成员已被撤销。端点
公告是短期密文；签名成员目录存入独立 mesh-networks.json。
