# 开发顺序与验收

产品定位已修订为通用组网工具。下一阶段优先完成：连接方向与网络身份分离、成功方向记忆、可管理的 STUN 列表、认证地址同步、持久配对和无需登录的 Windows 服务。界面只展示组网、虚拟 IP 与质量；特定应用优化单独可选。验收增加创建端/加入端分别提供 TCP 和 UDP 应用服务、两端分别测速、GUI 关闭及未登录时组网持续工作。下文历史串流场景保留为性能证据，不再限定产品基础。

2026-10-10 更新：已实现原生双端、独立 TCP STUN/UPnP 映射、EasyTier 封装、中文界面、邀请与质量测试，并通过完整路径 50 Mbps / 180 秒零丢包。见[实测报告](初版实测报告-20261010.md)。下表是此前估计，保留作规划记录，不是当前剩余工期；全新系统安装、小时级串流、换网恢复、短码发现和完整服务管理仍未验收。

这是完整产品的后续工作清单，不代表下表全部已经实现。以下工作量是单人专注开发、测试环境持续可用条件下的初步工程估计；驱动兼容及路由器行为会影响周期。

| 阶段 | 交付与关键修改 | 验收 | 初估剩余工作量 |
|---|---|---|---|
| M1 原生传输 | `native_backend.cpp`、`native_server.cpp` 及上游适配；WinDivert 生命周期、异常恢复 | 原生双端公网互通，与已验证路径做 A/B，协议兼容与长时间资源稳定 | 4–8 个工作日 |
| M2 原生映射 | 新建 TCP STUN、保活、路由器租约与映射代次管理模块 | 无 Lucky 进程时独立映射成功；与现有 Lucky 同环境对照；公网端口变更可恢复 | 5–10 个工作日 |
| M3 组网与配对 | Windows 服务、EasyTier 进程适配、身份和端口分配、发现服务与邀请流程 | 两台干净 Windows 只安装本软件即可配对并获得虚拟 IP；无业务中继 | 5–8 个工作日 |
| M4 串流与安装 | 桌面界面、签名组件封装、更新回滚、质量诊断 | 50 Mbps 串流长测、晚高峰重复、休眠/断网恢复、干净系统安装卸载 | 5–10 个工作日 |

总体按约 **4–8 周**量级预估，不把“能编译”算成完整服务端移植完成。若 M1 无法保持已有链路表现，暂停上层安装器工作，先解决数据通道。

## M1 下一次真实网络最小验证

1. 保留当前成功的完整 PoC 和其独立 Lucky 规则；确认不在游戏会话中，安排独立测试端口和独立虚拟网段。先做局域网，后做公网。
2. 核实两端 Windows、已签名 WinDivert 的版本和驱动共存情况；首轮只复用已存在驱动，不通过测试脚本升级或替换它。缺少驱动则先准备可审查的正式安装步骤。
3. **先替换一端**：Npcap/easy-faketcp Windows 客户端对原生 Windows 服务端，继续使用 Lucky 直接映射。验证三次握手、HTTP 特征、加密及双向 UDP；若失败，回到原 WSL 服务端定位差异。
4. 再替换客户端为原生 WinDivert。注意这里从 Winsock 辅助 TCP 握手变为 udp2raw 自己构造握手，是尚未验证的差异，必须单独记录，不能假定 QoS 分类一定相同。
5. 裸隧道依次测 10、40、50 Mbps，每档观察 CPU/队列/错误计数；然后经 EasyTier 虚拟网卡复测。短测先 20 秒，达到后做 180 秒。1200 和 1300 字节及双向控制流都要覆盖。
6. 先保持现有 HTTP Host 做协议对照，再在相近时段交错测试 HTTP 开/关。同一网卡、同一端点、同一有效码率；不把时间变化解释为域名效果。
7. Moonlight 40 Mbps 至少 10 分钟，50 Mbps 至少 30 分钟，再做晚高峰复测。记录串流统计中的网络丢帧、解码丢帧、码率和具体延迟字段。50 Mbps UDP 平均吞吐不足以保证视频峰值。

M1 目标：参考条件下 50 Mbps / 180 秒业务零丢包，串流无持续网络丢帧；原生版延迟分布不显著劣于相同时段的成功 PoC。验收同时记录可用带宽上限，不能把 60 Mbps 当成已有零丢包能力。

## M2 零配置映射验收

- 软件自己完成家庭路由器自动映射；不要求用户先开 Lucky 页面。
- 外部配对端能用 FakeTCP 验证，STUN 结果与业务实际目标一致。
- 停用/恢复保活、路由器重建映射、地址变化后能重新直连。
- 对端 Symmetric NAT 可以作为主动连接方；双方均不具备可达条件时展示可操作原因。
- 规则冲突不会覆盖已有 Lucky/串流映射；卸载只移除本软件租约。

## M3/M4 产品验收

- 两台没有 Lucky、EasyTier、Python、WSL 的 Windows 可完成安装和配对。
- 配对码不能被枚举加入；过期、撤销、重复端点更新均受控。
- 本机可直接说明：外层传输、目标节点、P2P 状态、有效带宽、丢包、延迟、网卡实际速率。
- 关闭发现服务后既有串流继续工作；断开直连不能改由服务转发业务。
- 重启、睡眠唤醒、以太网/Wi-Fi 切换、组件退出能诊断并恢复。
- 禁止空载状态未经用户操作自动执行满带宽压测；串流期间不后台压测。
- 安装、卸载和失败回滚有所有权检查；正常软件生命周期不依赖打开 PowerShell 或 SSH。

## 回退

开发阶段回退到已验证的 `validation/udp2raw-et-stream-20261009` 包。原生测试独立配置、独立端口，不能覆盖它的二进制和密钥。正常 TCP P2P 保留为用户可选的应急方案，并清楚提示其可靠有序传输特性；不作为无提示回退。
