# 开发与构建

环境：Windows x64、.NET SDK 10、CMake、Ninja、MinGW-w64；原生测试使用 Python 3，MSI 使用 WiX。运行包不要求用户安装这些工具。

```powershell
.\scripts\Build.ps1 -Test
dotnet run --project tests/StreamLink.Tests -c Release -p:StreamLinkPersonalFeature=true
dotnet run --project tests/StreamLink.MeshConnectionTests -c Release -p:StreamLinkPersonalFeature=true
dotnet run --project tests/StreamLink.WebTests -c Release -p:StreamLinkPersonalFeature=true
```

冻结并提交源码后，使用现有打包入口：

```powershell
.\scripts\Package-AqPersonal.ps1 -OutputRoot ..\releases -DependencyCache .\out\downloads -Version 1.1.0-rc.1 -MsiVersion 1.1.9 -PublicationApproved
.\scripts\Package-UnifiedLinux.ps1 -OutputDirectory ..\releases\linux-build -Version 1.1.0-rc.1
```

以上版本是当前正式 Release 沿用的构建标识。后续发布使用新的应用版本和递增的 MSI 版本；冻结的输出目录不能覆盖。正式发布状态由 GitHub Release 元数据记录，保留构建包中的实际版本和验证结果。

脚本名称沿用开发期命名。当前 Windows 打包入口是 `Package-AqPersonal.ps1`，Linux 是 `Package-UnifiedLinux.ps1`。依赖缓存需要官方 Wintun 0.14.1、WinDivert 2.2.2 及对应源码包；构建中会核对驱动签名与固定哈希。Linux 打包另需 WSL 中的 CMake、Ninja 与编译工具。

`src` 是应用与服务，`transport` 是原生传输及网卡桥接，`tests` 与 `scripts` 保存测试和构建入口。`out`、各项目 `bin/obj` 属于可重建产物；历史测试证据与私人配置应先归档，再清理 `artifacts`。

后续三机更新只保留当前版和上一个可回退版本。新版验证正常后，清理重复安装包、上传暂存、解压副本及测试临时目录；上一版只保留一套程序与匹配设置备份。当前安装维护所需的 MSI、生产设置、网络身份和用户日志保留。清理只针对可重建产物和确认闲置的文件，保留当前源码、Git 历史、开发工具及依赖缓存。

目录用途：`installer` 保存 MSI 界面，`packaging/linux` 保存 Linux 安装入口，`third-party` 保存官方网络组件的头文件及许可。根目录 `CMakeLists.txt` 与 `Directory.Build.targets` 分别管理原生和 .NET 构建，`.gitattributes` 保证 Linux 脚本的换行格式，不能按文件年代删除。

早期自研内核驱动、旧 CLI、独立协调部署脚本和旧版本打包工具已退役；对应代码可通过 Git 历史查阅。`tests/ConWU.HttpsPoc` 是仍在计划中的独立实验，不进入当前产品包。

发布附件包含对应源码、SBOM、哈希和验证范围。版本标记为正式版，不代表所有网络、八台设备或长期稳定性矩阵都已覆盖；具体以版本说明为准。
