# 来源与依赖

| 组件 | 固定来源 | 本轮使用方式 | 注意事项 |
|---|---|---|---|
| udp2raw HTTP 分支 | MikeWang000000/udp2raw `c4995eaad3576bd7bca872fe25bc93b519acdfdd` | 复制 C/C++ 源码及依赖到 `transport/udp2raw`，原生修改只在此处 | 顶层 MIT；AES、libev 等保留各自版权声明 |
| WinDivert | basil00/WinDivert `v2.2.2` / 2.2.2-A x64 包 | 官方 DLL 与签名驱动随包，动态加载；本次实测复用已有驱动 | 按 LGPLv3 使用，包内提供许可证、对应源码及原构建脚本 |
| EasyTier | 本地已验证二进制 2.6.4-8428a89d；源码 `8428a89d2dabc94c97d370ec607c6ca142473626` | 未修改 core/cli，以独立进程随包 | LGPL-3.0，包内提供对应源码、版本和二进制 SHA256；未声称本轮重建或位级可复现 |
| Wintun | 官方 0.14.1 amd64 | 原样 DLL 随包，SHA256 与已验证组件相同 | 官方 Prebuilt Binaries License 随包 |
| .NET | SDK 10.0.401，自包含 Runtime 10.0.12 | GUI/CLI 自包含发布 | MIT 与第三方声明随包，用户无需安装运行时 |
| Lucky | 2.27.2；公开仓库 `b4cf9edc9d8ffb266b8bb0f47193c90b16ae5850` | 只读研究及现有成功路径参考 | 公开代码只到 1.4.10，无 2.27.2 STUN 源码；未打包闭源程序 |
| Natter | `ce1427650178167d2330c490d2e5cd979223e9a4` | 阅读 TCP STUN 和保活实现，未复制代码到产品 | GPLv3；产品映射模块已按标准独立实现 |
| Npcap | 已有成功 PoC 使用 | 原生工程不依赖，不随包分发 | 自由下载版本不能直接当作允许重分发/静默安装的组件 |
