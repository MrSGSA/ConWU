# 使用 StreamLink

## 安装与更新

下载 Release 中的 `StreamLink-1.0.1-x64.msi`，两端分别安装。更新前结束串流，安装器会更新后台程序，保留现有网络、设备设置和自启选择。安装后从桌面或托盘打开 WebUI。

日常不需要管理员权限。关闭浏览器不会断开网络；需要停止连接时，在概况页点击“断开”。卸载从 Windows“已安装的应用”进行。

## 选择连接方式

**自建协调服务器**：两端填写同一个 HTTPS 协调地址。一端创建网络并生成六位配对码，另一端输入配对码申请加入。核对双方显示的校验码后，由主机同意。

**已有入口**：可填写公网 IP:端口、域名:端口或 HTTPS 订阅。主机选“本机入口”，加入端选“目标主机的入口”。入口需要通向主机的 StreamLink 接收端口，默认 `44680`。普通 TCP 代理和其他组网软件自己的隧道端口不能直接当作这个入口。

无服务器模式使用“主机入口＋六位配对码”，也可由主机生成完整直连邀请。加入页会自动识别短码或完整邀请。完整邀请包含预授权凭据，只发给准备加入的设备。

业务协议两端保持一致。默认 FakeTCP＋HTTP，UDP 是手动选项，不会自动回退。

## 使用 Lucky 等已有打洞工具

Lucky 负责建立并维护可达映射，StreamLink 使用实际返回的公网 IP 和端口。

以路由器端口转发为例，可以让 Lucky 使用本地 `44780` 探测，路由器将外部 `44780` 转发到主机 `44680`。Lucky 与 StreamLink 不能争用同一个本地监听端口。上级 NAT 可能再次改写公网端口，应发布 Lucky 实际返回的结果。

推荐使用带鉴权的 HTTPS 订阅；地址有变化时由 Lucky 上报，StreamLink 自动读取。订阅可以返回：

```text
streamlink=203.0.113.42:44680
streamlink=edge.example.com:44680
```

共享订阅在 URL 最后加 `#streamlink`，例如 `https://example.com/entries?token=只读令牌#streamlink`。缺少标签时会明确报错，避免读到其他应用的入口。写入令牌只放上报端，客户端使用只读令牌；完整订阅链接也需要保密。

自动更新默认每 60 秒一次，可在设置中调整。订阅暂时失败会保留同一来源上次成功的地址；地址更新不会拆掉健康连接。解析成功后，还要通过设备认证及双向验证，才算真正直连。

TXT 仍可选用，但内容公开，也受 DNS 缓存影响。仅使用 HTTPS 就能完成地址更新。普通 DDNS 只更新 IP，公网端口变化时仍需要其他方式告知客户端。

## 开始串流

连接成功后，在概况页找到对方的虚拟 IP，将它填进 Moonlight。建议先确认画面、声音与输入正常，再提高码率。日志中的“实际直连入口”可用于核对正在使用哪个公网入口。

本版为 IPv4 直连组网，不提供业务中继。主机与两个成员分别连通，不代表这两个成员之间也一定能直连。

## 回退

保留上一版安装包。需要回退时，先断开网络并等后台停止，再卸载新版、安装旧版。不要跨电脑复制 DPAPI 配置。

回退到 rc.13 或更早版本前，请把带 `#streamlink` 的来源换成旧版支持的专用订阅。日常使用的其他管理通道可继续保留。
